Site Admin

One admin page for every course site. Manage the top-level course directory, or pick a course below to edit its sections, lessons, and lock states.

How this works — read before your first use: this site has no backend yet, so everything below only changes what you see in this browser tab.
  1. Make your edits (course list, or a specific course's lessons).
  2. Click the relevant "Generate updated file(s)" button.
  3. Download the file(s) it produces.
  4. Upload each one to your web host, replacing the existing copy in the matching location — courses-config.js goes at the site root; a course's site-structure.js/lessons-config.js/videos-config.js go inside that course's own folder (e.g. y9-computing/lessons-config.js).
Important: adding a course or a lesson here only adds it to a listing — it does not create the actual folder/files. A brand-new course needs its skeleton built (same as robotics-club/y7-computing/etc.) and a brand-new lesson's resources (the files/links listed when a lesson is expanded) need their actual HTML pages written before their file paths will work. Leave a lesson locked until every resource inside it actually exists, or students will hit a broken link when they expand and click it.
