Arrays: 2D Declaration & Use

A 1D array is a list. A 2D array is a grid — rows and columns, both indexed, both looped through together.

01

From list to grid

A 1D array is perfect for a single list of values. But plenty of real data is naturally arranged in a grid — a noughts and crosses board, a spreadsheet, a seating plan, a set of pixels. A 2D array extends the same idea with a second dimension: every element now needs two index values to identify it — its row, and its column.

02

Declaring a 2D array

pseudocode
DECLARE <identifier> : ARRAY[<lower1>:<upper1>,<lower2>:<upper2>] OF <data type>

The first pair of bounds describes the rows; the second pair describes the columns. Everything else works exactly like a 1D array — fixed size once declared, every element the same data type.

pseudocode
DECLARE Board : ARRAY[1:3,1:3] OF CHAR

This declares a 3×3 grid of characters — enough to represent a noughts and crosses board, with rows 1 to 3 and columns 1 to 3.

03

Accessing and assigning elements

An element is referred to with both indices inside the same pair of square brackets, separated by a comma — row first, then column, matching the order used in the declaration.

pseudocode
Board[1,1] ← 'X'
Board[2,2] ← 'O'
OUTPUT Board[1,1]   // outputs X
Row, then column — every time Board[2,3] means row 2, column 3. Writing Board[3,2] instead refers to a completely different cell — row 3, column 2. The order always matches how the array was declared, so keep it consistent throughout a program.
04

Populating with nested loops

Filling every cell of a grid needs two loops, one inside the other: the outer loop moves down the rows, and for each row, the inner loop moves across every column.

pseudocode
DECLARE Board : ARRAY[1:3,1:3] OF CHAR
FOR Row ← 1 TO 3
   FOR Col ← 1 TO 3
      Board[Row,Col] ← '-'
   NEXT Col
NEXT Row

For every single pass of the outer loop (one row), the entire inner loop runs start to finish (all its columns) before the outer loop advances to the next row. For a 3×3 grid, that's 3 outer passes × 3 inner passes = 9 assignments in total.

05

Traversing and counting

The same nested-loop pattern visits every cell to read a grid, not just to fill it — for example, counting how many cells hold a particular value.

pseudocode
DECLARE Count : INTEGER
Count ← 0
FOR Row ← 1 TO 3
   FOR Col ← 1 TO 3
      IF Board[Row,Col] = 'X' THEN
         Count ← Count + 1
      ENDIF
   NEXT Col
NEXT Row

06

Common mistakes

  • Swapping row and column. Board[Col,Row] instead of Board[Row,Col] silently reads or writes the wrong cell — it won't cause an error, just wrong results, which makes it especially easy to miss.
  • Using one loop instead of two. A single FOR loop can visit every index of a 1D array, but a 2D array genuinely needs two nested loops to reach every cell — there's no way to cover a whole grid with just one loop counter.
  • Off-by-one in either loop. Exactly the same risk as with 1D arrays, but now doubled — check both the outer loop's range and the inner loop's range against the array's declared bounds.
The inner loop completes fully, every time A common misreading is to assume the two loops "interleave" somehow. They don't: for row 1, every column from the inner loop's start to its end runs before row 2 even begins. Trace through slowly if you're ever unsure of the order — the simulators above show exactly this order in action.
