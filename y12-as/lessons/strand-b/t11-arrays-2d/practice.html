E

Exam-style questions

A student writes this code to count empty cells ('-') in a 3×3 board, but it gives the wrong answer:

DECLARE Count : INTEGER Count ← 0 FOR Row ← 1 TO 3 IF Board[Row,Row] = '-' THEN Count ← Count + 1 ENDIF NEXT Row

Identify the bug and explain how to fix it.

Reveal model answer

The bug: there is only one loop, and it uses Row for both indices — Board[Row,Row] only ever checks the three diagonal cells (1,1), (2,2), (3,3), never any of the other six cells in the grid.

Fix: a second, nested loop is needed for the column index, checking every column for each row: FOR Row ← 1 TO 3 / FOR Col ← 1 TO 3 / IF Board[Row,Col] = '-' THEN Count ← Count + 1 / ENDIF / NEXT Col / NEXT Row.

Explain why a 2D array genuinely needs two nested loops to visit every cell, rather than one loop that simply runs more times (e.g. a single loop from 1 to 9 for a 3×3 grid).

Reveal model answer

A single loop counter can only ever hold one number at a time, but every element of a 2D array needs two separate index values — a row and a column — to be identified. A loop running from 1 to 9 would produce nine single numbers, not nine row-and-column pairs, so there would be no direct way to turn that counter into a valid [Row,Col] reference without extra calculation to convert it back into two coordinates. Two nested loops naturally provide exactly the two numbers needed, one from each loop, with no extra conversion required.
