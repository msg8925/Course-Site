01

Why this matters

Iteration is how a program repeats an action without the programmer writing it out over and over. Every loop you'll meet boils down to one core question: how does the program know when to stop? The answer — a fixed count, a condition checked before each pass, or a condition checked after — is exactly what separates FOR, WHILE, and REPEAT...UNTIL.

As with selection last week, you'll need to read and write all three forms in both Cambridge pseudocode and Python.

02

FOR loops

Use a FOR loop when you know, in advance, exactly how many times to repeat something — this is called count-controlled iteration.

Cambridge pseudocode
FOR i ← 1 TO 5
    OUTPUT i
NEXT i
Python
for i in range(1, 6):
    print(i)
Translation trap

Pseudocode's FOR i ← 1 TO 5 is inclusive of both ends — it runs for i = 1, 2, 3, 4, 5 (five times). Python's range(1, 6) stops before its second argument, so to get the same five values you need range(1, 6), not range(1, 5). This off-by-one mismatch is one of the most common translation mistakes.

A STEP clause changes the increment — including counting downwards:

Cambridge pseudocode
FOR i ← 10 TO 0 STEP -2
    OUTPUT i
NEXT i
Python
for i in range(10, -1, -2):
    print(i)

Notice the range's stop value is -1, not 0 — again to compensate for Python excluding the stop value, this time counting downward.

04

      
WHILE loops

      
WHILE loops are condition-controlled, and check their condition before every iteration — including before the very first one. If the condition is false to start with, the loop body might not run at all.


      

        

          
Cambridge pseudocode

          
WHILE count < 3 DO
    OUTPUT count
    count ← count + 1
ENDWHILE

        

        

          
Python

          
while count < 3:
    print(count)
    count += 1

        

      

    


    

      
05

      
REPEAT...UNTIL loops

      
REPEAT...UNTIL is also condition-controlled, but checks its condition after each iteration. This guarantees the loop body runs at least once, no matter what.


      

        

          
Cambridge pseudocode

          
REPEAT
    OUTPUT count
    count ← count + 1
UNTIL count >= 3

        

        

          
Python

          
while True:
    print(count)
    count += 1
    if count >= 3:
        break

        

      


      

        Two traps in one
        
First: Python has no direct REPEAT...UNTIL keyword, so it's emulated with while True: plus an if and a break. Second: pseudocode's UNTIL means "stop when this becomes true" — the opposite sense to WHILE, which means "keep going while this is true." UNTIL count >= 3 and WHILE count < 3 are testing complementary conditions on purpose.

Choosing the right loop

      

        
SituationLoop type

        
You know exactly how many times to repeat, in advanceFOR

        
You need to check the condition before the first attempt — it might not run at allWHILE

        
The loop body must run at least once, condition checked afterwardsREPEAT...UNTIL

      

      

        A classic REPEAT...UNTIL use case
        
Validating user input is the textbook example: you have to ask the user for input at least once before you can check whether it's valid — a perfect fit for a post-condition loop.

      

    


    

      
08

      
Key takeaways

      
    
        
  • FOR loops are count-controlled; pseudocode's TO is inclusive, but Python's range() excludes its stop value — adjust accordingly.
    • 
        
  • WHILE loops check their condition before each pass, so the body may run zero times.
    • 
        
  • REPEAT...UNTIL loops check their condition after each pass, so the body always runs at least once. Python emulates this with while True: and a break.
    • 
        
  • WHILE conditions describe when to keep going; UNTIL conditions describe when to stop — they're usually opposite senses of the same test.
    • 
        
  • Trace tables work the same way as for selection, but now track variable values across every pass through the loop.
