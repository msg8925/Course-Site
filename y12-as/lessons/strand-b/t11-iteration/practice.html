3

How many times does OUTPUT execute in this loop?

Pseudocode
count ← 5
WHILE count > 0 DO
    OUTPUT count
    count ← count - 1
ENDWHILE
Show full working

count takes the values 5, 4, 3, 2, 1 before the condition becomes false at count = 0. OUTPUT runs 5 times.

4

What is the final value of num after this loop ends?

Pseudocode
num ← 10
REPEAT
    num ← num - 3
UNTIL num <= 0
Show full working

10 → 7 → 4 → 1 → −2. At −2 the condition num <= 0 is finally true, so the loop stops. Final value: −2.

9

How many times does the loop body execute, and what is the final value of x?

Pseudocode
x ← 8
WHILE x > 10 DO
    x ← x + 1
ENDWHILE
OUTPUT x
Show full working

x = 8 is not greater than 10, so the WHILE condition is false before the first pass. The loop body never runs. Final value of x: 8 (unchanged).

Translate this Python into Cambridge pseudocode.

Python
count = 0
while True:
    count += 2
    if count >= 10:
        break
print(count)
Show model answer

The while True / break pattern is Python's emulation of REPEAT...UNTIL:

Pseudocode
count ← 0
REPEAT
    count ← count + 2
UNTIL count >= 10
OUTPUT count

E

Exam-style question

A longer, multi-part question.

12

A vending machine program repeatedly asks the customer to insert coins until the total inserted is at least 200 cents. Each time, it adds the coin's value to a running total and displays the total so far.

(a) Which loop type (FOR, WHILE, or REPEAT...UNTIL) is most appropriate here? Justify your answer.
(b) Write Cambridge pseudocode for this loop, using INPUT coin to read a coin's value and OUTPUT total to display the running total.
(c) Complete a trace table for a customer who inserts coins of value 50, 75, and 100 (in that order).

Show model answer

(a) REPEAT...UNTIL. The customer must insert at least one coin before the total can be checked at all — the action has to happen before the condition can be tested, which is exactly what a post-condition loop guarantees.

(b)

Pseudocode
total ← 0
REPEAT
    INPUT coin
    total ← total + coin
    OUTPUT total
UNTIL total >= 200

(c) coin = 50 → total = 50. coin = 75 → total = 125. coin = 100 → total = 225. The loop stops after the third coin, since 225 ≥ 200.
