E

Exam-style question

A longer question bringing arrays and functions together.

13

Write a FUNCTION called CalculateAverage that takes an array of exactly 5 INTEGER exam scores as a parameter, and RETURNS their average as a REAL. Include the full function header, declaration of any variables you need, and the logic to calculate the average.

Show model answer
Pseudocode
FUNCTION CalculateAverage(scores : ARRAY[1:5] OF INTEGER) RETURNS REAL
    DECLARE total : INTEGER
    DECLARE i : INTEGER
    total ← 0
    FOR i ← 1 TO 5
        total ← total + scores[i]
    NEXT i
    RETURN total / 5
ENDFUNCTION

Notice this brings together several conventions at once: an array parameter, a FOR loop (from an earlier lesson) to visit every element, and a RETURN statement handing back a single REAL value.
