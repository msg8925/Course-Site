01

Why this matters

Selection is how a program makes decisions — running different code depending on whether a condition is true or false. Almost no useful program runs top to bottom with no branching at all.

You'll need to read and write selection in two forms: Cambridge's exam pseudocode, and Python. They express exactly the same logic with different syntax, so today is as much about translating fluently between them as it is about the logic itself.

02

IF...THEN...ELSE

The simplest form of selection runs one block of code if a condition is true, and (optionally) a different block if it's false.

Cambridge pseudocode
IF mark >= 50 THEN
    OUTPUT "Pass"
ELSE
    OUTPUT "Fail"
ENDIF
Python
if mark >= 50:
    print("Pass")
else:
    print("Fail")

Notice the structural differences: pseudocode uses THEN and a closing ENDIF; Python uses a colon and relies on indentation to show which lines belong to which branch, with no closing keyword at all.

Nested IF and multi-way ELSE IF

An IF can contain another IF inside it (nesting), or you can chain conditions with ELSE IF to test several possibilities in order, stopping at the first one that's true.

Cambridge pseudocode
IF score >= 90 THEN
    grade ← "A"
ELSE IF score >= 80 THEN
    grade ← "B"
ELSE IF score >= 70 THEN
    grade ← "C"
ELSE
    grade ← "F"
ENDIF
Python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
Worth noticing

Only one branch ever runs. Even if score is 95 (which is also ≥ 80), the first true condition wins and the rest are skipped entirely.

04

      
CASE OF...OTHERWISE...ENDCASE

      
When a variable can take one of a small number of discrete, exact values — not ranges — a CASE statement is usually clearer than a long chain of ELSE IFs testing equality over and over.


      

        

          
Cambridge pseudocode

          
CASE OF choice
    1 : OUTPUT "Add item"
    2 : OUTPUT "Remove item"
    3 : OUTPUT "View cart"
    OTHERWISE : OUTPUT "Invalid choice"
ENDCASE

        

        

          
Python

          
if choice == 1:
    print("Add item")
elif choice == 2:
    print("Remove item")
elif choice == 3:
    print("View cart")
else:
    print("Invalid choice")

        

      


      

        Choosing between them
        
Use CASE for a fixed set of exact values (menu numbers, day names, single characters). Use nested IF / ELSE IF for ranges, or when the conditions involve comparisons like >, <, or combinations of variables.

      


      
Python 3.10 and later also has a dedicated match/case statement that maps onto CASE OF even more directly — useful to know, though the if/elif chain above works in any version and is what you'll most often see expected.

Trace tables

      
A trace table tracks the value of every relevant variable and condition as an algorithm runs, for a specific set of inputs. It's the standard way to check (or prove) exactly what a piece of code will do, without running it.


      

        
Worked example

        

          
Pseudocode

          
IF num > 0 THEN
    IF num MOD 2 = 0 THEN
        OUTPUT "Positive even"
    ELSE
        OUTPUT "Positive odd"
    ENDIF
ELSE
    IF num = 0 THEN
        OUTPUT "Zero"
    ELSE
        OUTPUT "Negative"
    ENDIF
ENDIF

Notice which "second check" applies depends on the result of the first one — that's exactly what nesting means. Only one path through the whole structure is ever taken for a given input.

Translating between the two

      
Most translation mistakes come from a handful of small syntax differences. Keep this table handy.

      

        
IdeaCambridge pseudocodePython

        
Assignment←=

        
Equality test===

        
Block start / endTHEN ... ENDIF: and indentation (no end marker)

        
RemainderMOD%

        
Logic operatorsAND, OR, NOTand, or, not

        Common mistake
        
Writing IF x = 5 in Python instead of if x == 5:. A single = in Python is always assignment, never a comparison — and using it inside an if is a syntax error.

      

    


    

      
08

      
Key takeaways

      
    
        
  • IF...THEN...ELSE...ENDIF in pseudocode becomes if / else with a colon and indentation in Python — no closing keyword needed.
    • 
        
  • Chained ELSE IF (pseudocode) or elif (Python) tests conditions in order and stops at the first match — only one branch ever runs.
    • 
        
  • CASE OF...OTHERWISE...ENDCASE suits a fixed set of exact, discrete values; nested IF suits ranges and more complex conditions.
    • 
        
  • A trace table records every relevant variable and condition result for a given input, so you can determine the output without running the code.
    • 
        
  • Watch for the small syntax traps when translating: ← vs =, = vs ==, and pseudocode's explicit ENDIF/ENDCASE versus Python's indentation.
