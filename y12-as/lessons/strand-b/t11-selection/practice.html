Exam-style question

A longer, multi-part question.

13

A ride-sharing app calculates a fare based on distance (km) and whether it's peak time.
• If it's peak time: fare = distance × 2 (dollars per km)
• If it's not peak time: fare = distance × 1.5 (dollars per km)
If the calculated fare is less than 5, a minimum fare of 5 is charged instead.

(a) Write Cambridge pseudocode using IF...THEN...ELSE to calculate the fare, including the minimum fare rule.
(b) State whether CASE OF would be a suitable alternative construct here, and justify your answer.
(c) Complete a trace table for: distance = 2, peak = TRUE; distance = 10, peak = FALSE; distance = 1, peak = TRUE.

Show model answer

(a)

Pseudocode
IF peak = TRUE THEN
    fare ← distance * 2
ELSE
    fare ← distance * 1.5
ENDIF
IF fare < 5 THEN
    fare ← 5
ENDIF
OUTPUT fare

(b) CASE OF would not be suitable. The decision depends on a boolean condition combined with a calculated numeric comparison (fare < 5), not a small set of discrete, known values — which is what CASE requires.

(c) distance=2, peak=TRUE: fare = 2×2 = 4; 4<5 TRUE → fare = 5; Output 5.
distance=10, peak=FALSE: fare = 10×1.5 = 15; 15<5 FALSE → fare stays 15; Output 15.
distance=1, peak=TRUE: fare = 1×2 = 2; 2<5 TRUE → fare = 5; Output 5.
