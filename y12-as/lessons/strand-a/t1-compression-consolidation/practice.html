RLE on rows

Encode each row exactly as you would a 1D string: count, then value.

1

RLE-encode this row: 11100111

Show full working

3 ones, 2 zeros, 3 ones: 3B2W3B.

2

RLE-encode this row: 00000001

Show full working

7 zeros, 1 one: 7W1B.

3

A 4×4 image has these rows, top to bottom: 1111, 1111, 0000, 0000. Encode each row, then calculate the overall compression ratio (each run costs 2 characters: one digit for the count, one letter for the colour).

Show full working
1111 -> 4B (2 chars) 1111 -> 4B (2 chars) 0000 -> 4W (2 chars) 0000 -> 4W (2 chars)

Total encoded = 8 characters. Original = 16 pixels. Ratio = 16 ÷ 8 = 2.

Multi-step calculations

File size, then compression — in order.

4

An image is 300 × 200 pixels, 8-bit colour depth. Calculate the uncompressed file size in bytes, then the compressed size if the compression ratio is 5x.

Show full working
300 × 200 × 8 = 480,000 bits = 60,000 bytes 60,000 \u00f7 5 = 12,000 bytes

Answer: 12,000 bytes.

5

An uncompressed image is 2,000,000 bytes. After compression it becomes 250,000 bytes. Calculate the compression ratio.

Show full working
2,000,000 \u00f7 250,000 = 8

Answer: 8.

6

A 1200 × 800 pixel image at 24-bit colour depth is compressed with a ratio of 15x. Calculate the compressed file size in bytes.

Show full working
1200 × 800 × 24 = 23,040,000 bits = 2,880,000 bytes 2,880,000 \u00f7 15 = 192,000 bytes

Answer: 192,000 bytes.

C

Lossy vs lossless scenarios

Justify your choice against the specific scenario, not a general rule.

7

A hospital stores X-ray scans that must remain diagnostically exact, with no loss of detail. Which type of compression should be used, and why?

Show model answer

Lossless. Medical images must be pixel-perfect for accurate diagnosis; any loss of detail could hide or distort something clinically significant.

8

A video streaming service wants to minimise bandwidth for users with slow internet connections, and small imperfections in picture quality are barely noticeable. Which type of compression should be used, and why?

Show model answer

Lossy. It achieves a much greater reduction in file size, and the minor quality loss is an acceptable trade-off given the platform's priority of fast streaming on limited bandwidth.

9

A software company distributes program installation files, where any corrupted or altered code would cause the program to malfunction. Which type of compression should be used, and why?

Show model answer

Lossless. Program files must remain byte-for-byte exact after decompression, or the software could crash or behave incorrectly.

D

Mixed short answer

Common exam-style misconceptions, tested directly.

10

True or false: a higher compression ratio always means lower image quality.

Show full working

False. The ratio alone doesn't tell you whether quality was lost — lossless compression can also achieve a high ratio on suitable data (e.g. a simple image compressed well with RLE) with no quality loss at all. Ratio and lossy/lossless are separate questions.

11

A student claims "RLE always makes files smaller." Explain why this is not correct, using an example.

Show model answer

RLE only helps when there are long runs of repeated values. On data that alternates frequently — such as the row 01010101 — every value forms its own run of length 1, so each pixel needs its own count-and-value pair. This produces an encoding longer than the original (16 characters from 8 pixels, in the convention used in this course), making the file bigger rather than smaller.

Exam-style question

A longer, multi-part question bringing everything together.

12

A hospital's X-ray archive stores each scan as a 2000 × 1500 pixel image using 16-bit colour depth.

(a) Calculate the uncompressed file size of one scan, in bytes.
(b) The hospital uses a lossless compression algorithm that achieves a compression ratio of 3x on these scans. Calculate the compressed file size.
(c) Justify why the hospital uses lossless rather than lossy compression for these scans.
(d) A simplified black-and-white section of one scan is represented as an 8-pixel row: 00111100. RLE-encode this row.

Show model answer

(a)

2000 × 1500 × 16 = 48,000,000 bits 48,000,000 \u00f7 8 = 6,000,000 bytes

(b)

6,000,000 \u00f7 3 = 2,000,000 bytes

(c) Medical scans must remain exact for accurate diagnosis. Lossy compression permanently discards detail, which could hide or distort a clinically important feature; lossless guarantees the decompressed scan is identical to the original.

(d) 2 zeros, 4 ones, 2 zeros: 2W4B2W.
