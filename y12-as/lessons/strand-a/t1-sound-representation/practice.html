3

Put these four ADC steps into the correct order by typing the letters in order (e.g. "WXYZ").

  • X Sound enters as a continuous analogue signal
  • Y Encode each quantized level as binary

Correct order: X (sound arrives) → Z (sample it) → W (quantize each sample) → Y (encode as binary).

B

File size calculations

Use: file size (bits) = sample rate × bit depth × duration × channels.

4

Calculate the file size, in bytes, of a 5-second mono recording sampled at 8,000 Hz with 8-bit resolution.

Show full working
8,000 × 8 × 5 × 1 = 320,000 bits 320,000 \u00f7 8 = 40,000 bytes

Answer: 40,000 bytes.

5

Answer: 529,200 bytes.

C

Trade-offs

Sample rate and bit depth each trade file size for a different kind of accuracy.

8

Explain the effect on both file size and accuracy of doubling the sample rate, keeping everything else the same.

Show model answer

File size doubles, since file size is directly proportional to sample rate. Accuracy improves in terms of timing detail — the recording captures faster changes in the wave more faithfully, which particularly improves the reproduction of higher-pitched sounds.

9

Explain the effect on both file size and accuracy of doubling the bit depth, keeping everything else the same.

Show model answer

File size doubles, since file size is directly proportional to bit depth. Accuracy improves in terms of amplitude precision — more available levels means each sample is quantized more precisely, reducing quantization error and making the recorded volume/amplitude sound less "grainy."

10

True or false: doubling both the sample rate and the bit depth together doubles the file size.

Show full working

False. File size depends on the product of sample rate and bit depth, so doubling both multiplies the file size by 2 × 2 = 4, not 2.

D

Mixed & applied

Bringing calculation and trade-off reasoning together.

11

A sound engineer doubles both the sample rate and the bit depth of a recording, keeping duration and channels the same. By what factor does the file size increase?

Show full working

Doubling the sample rate doubles the size; doubling the bit depth doubles it again: 2 × 2 = 4.

12

A student wants to reduce a recording's file size without changing its length or number of channels. Suggest two changes they could make, and state one downside of each.

Show model answer

Reduce the sample rate — downside: faster changes in the wave (higher-pitched detail) are captured less accurately.

Reduce the bit depth — downside: each sample is quantized less precisely, increasing quantization error and making amplitude sound more "grainy."

E

Exam-style question

A longer, multi-part question.

13

A voice memo app records mono audio at 16-bit resolution.

(a) The app currently uses a sample rate of 8,000 Hz. Calculate the file size, in bytes, of a 45-second recording.
(b) A user complains the recordings sound "muffled" and lack high-frequency detail. Suggest one change to the recording settings that would improve this, and explain your reasoning.
(c) If your suggested change in (b) doubles the relevant setting, state the new file size, in bytes, for the same 45-second recording.

Show model answer

(a)

8,000 × 16 × 45 × 1 = 5,760,000 bits 5,760,000 \u00f7 8 = 720,000 bytes

(b) Increase the sample rate. "Muffled" and lacking high-frequency detail points specifically to sample rate rather than bit depth, since sample rate determines how well fast (high-pitched) changes in the wave are captured.

(c) Doubling the sample rate to 16,000 Hz:

16,000 × 16 × 45 × 1 = 11,520,000 bits 11,520,000 \u00f7 8 = 1,440,000 bytes
