E

Exam-style questions

Two laptops, X (10.0.0.5) and Y (10.0.0.9), are on the same local network. Explain whether a router is involved when X sends data to Y, and which address is used to deliver it.

Reveal model answer

No router is needed. Both devices share the same network portion of their IP address (10.0.0.x), so X can tell Y is on the same local network. The switch delivers the frame directly using Y's MAC address — there's no need to leave the local network, so the router (which works with IP addresses to reach other networks) is never involved.

A technician says: "We don't need IP addresses — MAC addresses already uniquely identify every device in the world, so we could route the whole internet using just those." Explain the flaw in this argument.

Reveal model answer

MAC addresses are unique, but they carry no information about where a device is on the wider network of networks — they only identify hardware, not location or which network it's part of. Routers need a way to work out which direction to send data in, based on which network a destination belongs to; IP addresses are structured (network portion plus host portion) so that this decision can be made without knowing every single device's exact position in advance. Trying to route by MAC address alone would mean every router on the internet needing a direct record of literally every device that exists, with no way to group them by location — which does not scale.
