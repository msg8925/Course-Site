The three basic gates

A logic gate takes one or more binary inputs (0 or 1) and produces a single binary output, according to a fixed rule. Every logic circuit, however complex, is built entirely from these simple pieces.

03

Constructing a truth table systematically

A truth table must list every possible combination of inputs — miss one, and the table is incomplete. With n inputs, there are always exactly 2ⁿ possible combinations, since each input independently can be 0 or 1.

Number of inputsNumber of rows needed
12¹ = 2
22² = 4
32³ = 8
42⁴ = 16

To avoid missing or duplicating a row, list the combinations in order exactly as if counting in binary — the rightmost input column alternates every row, the next column every two rows, and so on:

ABC

100
101

111
Missing rows is the most common mistake With three inputs, a table with only 6 or 7 rows is automatically wrong, no matter how correct the values in it are — it's an easy thing to check for before working out a single output value.
04

Building a circuit from an expression

A logic expression combining more than one operation is built by chaining gates together — the output of one gate becomes an input to the next. Consider:

X = (A AND B) OR (NOT C)

This needs three gates: an AND gate taking A and B, a NOT gate taking C, and an OR gate taking the outputs of those first two gates as its own two inputs. The structure of the expression — what's grouped together — directly determines which gate's output feeds into which.
