E

Exam-style questions

A student says: "Packet switching is worse than just sending the whole file in one go, because it needs extra header data and reassembly work." Give two reasons packet switching is used despite this overhead.

Reveal model answer

Efficient sharing: because data is broken into small packets, many different devices' packets can be interleaved across the same network links at the same time, rather than one transfer monopolising a route for its whole duration.

Resilience: if part of the network becomes congested or a route fails partway through, only the remaining packets need to be sent a different way — the transfer doesn't have to restart completely or fail outright, which a single continuous stream over one fixed route could not offer.

Explain what would go wrong if a packet's header included the destination address but not a sequence number.

Reveal model answer

The destination address is enough to get every packet to the right device, but without a sequence number the receiving device would have no way of knowing which order the packets originally belonged in. Since packets can legitimately arrive out of order, the reassembled message could come out scrambled — the data would all be present, but not necessarily reconstructed correctly.
