Vector Graphics: Objects, Properties & Drawing Lists

01

Why this matters

A bitmap image is a grid of pixel colours — you met the whole calculation last week. A vector graphic takes a completely different approach: instead of storing a colour for every pixel, it stores a list of shapes and the instructions for drawing each one. That single difference in approach is what makes a vector logo look perfectly crisp whether it's the size of an icon or the size of a billboard.

02

How vector graphics are stored

A vector graphic file is built from three ideas:

  • Drawing objects — individual shapes, such as a line, rectangle, circle, or curve.
  • Properties — the values that define exactly how one object looks: its position, size, colour, line thickness, and so on.
  • The drawing list — the ordered sequence of objects that together make up the whole image. Order matters: an object later in the list is drawn on top of everything before it.

Worked example — a simple traffic light

1. Rectangle — position (10,10), size 40×100, fill black 2. Circle — centre (30,30), radius 12, fill red 3. Circle — centre (30,60), radius 12, fill amber 4. Circle — centre (30,90), radius 12, fill green

The rectangle is listed first deliberately — if it were listed last, it would be drawn on top and hide all three circles underneath it.

04

Scaling: the real difference

A bitmap has a fixed number of pixels. Enlarge it, and the software has to guess what colour to put in the new, larger squares — the result is a blocky, blurry image once you zoom in far enough.

A vector graphic has no pixels to run out of. Every time it's displayed, the software redraws each shape from its properties at whatever size is needed — a circle is still calculated as a perfect circle, however large.

06

Choosing vector or bitmap

VectorBitmap
Stored asA list of objects and their propertiesA grid of pixel colour values
ScalingNo quality loss — redrawn at any sizePixelates once enlarged beyond its resolution
Best suited toLogos, icons, line art, fonts, technical diagramsPhotographs and complex, continuously-varying images
Why not vector everything?

A photograph has continuous, irregular variation in almost every pixel — there's no small list of geometric shapes that could reasonably describe it. Bitmaps exist because some images genuinely need per-pixel detail; vector graphics exist because many others don't.

07

Key takeaways

  • A vector graphic is stored as a drawing list of objects, each with its own properties — not as pixels.
  • Order in the drawing list matters: later objects are drawn on top of earlier ones.
  • Vector graphics scale without quality loss, because they're redrawn from their properties at any size; bitmaps pixelate because they have a fixed number of pixels to work with.
  • Use vector for logos, icons, and line art that need to scale; use bitmap for photographs and other images with continuous, irregular detail.
