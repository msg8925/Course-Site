A

Objects & properties

Test your understanding of how vector graphics are structured.

1

Name the three core things a vector graphic file needs to store.

Show model answer

Drawing objects (the shapes), properties (the values describing each shape, such as position, size, and colour), and the drawing list (the ordered sequence the objects are drawn in).

2

List two properties you would expect a "circle" drawing object to have.

Show model answer

Any two of: centre position (x, y coordinates), radius, fill colour, outline colour, outline thickness.

3

In a drawing list, what determines which object appears "on top" when two objects overlap?

Show full working

The object that appears later in the drawing list is drawn on top.

4

A drawing list already has 5 objects in it. You want to add a new rectangle so that it appears on top of everything already there. Where in the list should it be added?

Show full working

At the end of the list (as the 6th object).

B

Scaling

The core practical difference between vector and bitmap.

5

True or false: enlarging a vector graphic causes it to become pixelated.

Show full working

False. Vector graphics are redrawn from their properties at any size, so they stay crisp.

6

True or false: enlarging a bitmap image causes it to become pixelated.

Show full working

True. A bitmap has a fixed number of pixels; enlarging it stretches those same pixels over a larger area, making them visible as blocks.

7

Explain why a vector graphic doesn't lose quality when it's scaled up.

Show model answer

A vector graphic isn't stored as fixed pixels — it's stored as a list of shapes and their properties. Whenever it's displayed, each shape is redrawn mathematically at whatever size is needed, so a circle is still calculated as a perfect circle regardless of scale, with no pixelation.

D

Applied reasoning

Bringing the storage model and the use-case together.

12

Explain why a vector graphic of a simple logo is typically a much smaller file than a bitmap of the same logo.

Show model answer

A simple logo might only need a handful of drawing objects (a few shapes and their properties) to describe completely, which takes very little storage. A bitmap of the same logo has to store a colour value for every single pixel in the image, regardless of how simple the actual picture is — which adds up to far more data for the same visual result.

E

Exam-style question

A longer, multi-part question.

13

A vector graphic shows a simple traffic light: three circles (red, amber, green) stacked vertically inside a rounded rectangle background.

(a) List the drawing objects needed for this image, in the order they should appear in the drawing list.
(b) State one property each for the rectangle and for one of the circles.
(c) Explain why a vector graphic is a more appropriate choice for this traffic-light icon than a bitmap, referencing how the two formats store image data.

Show model answer

(a) 1. Rounded rectangle (background). 2. Red circle. 3. Amber circle. 4. Green circle. The rectangle must be listed first, so the circles are drawn on top of it rather than being hidden underneath.

(b) Rectangle: e.g. its width and height, or its fill colour. Circle: e.g. its centre position, or its radius, or its fill colour.

(c) The icon is made entirely of simple geometric shapes, so it can be described compactly as a short list of objects and properties — far less data than storing every pixel in a bitmap. It will also stay crisp at any size, whether displayed small in an app or large on a road sign, because vector graphics are redrawn from their properties rather than relying on a fixed grid of pixels.
