A

Pixels & colour depth

Quick recap of the core vocabulary.

1

How many pixels are in a 100 × 50 image?

Show full working

100 × 50 = 5,000 pixels.

2

How many distinct colours can be represented with a 3-bit colour depth?

Show full working

23 = 8 colours.

3

How many bits are needed to represent exactly 64 distinct colours?

Show full working

26 = 64, so 6 bits.

4

What is the term for the number of bits used to represent each pixel's colour?

Show full working

Colour depth (also accepted: bit depth).

B

File size calculations

Use: file size (bits) = width × height × colour depth.

5

Calculate the file size, in bytes, of a 4 × 4 pixel image with 8-bit colour depth.

Show full working
4 × 4 × 8 = 128 bits 128 \u00f7 8 = 16 bytes

Answer: 16 bytes.

6

Calculate the file size, in bytes, of a 200 × 100 pixel image with 4-bit colour depth.

Show full working
200 × 100 × 4 = 80,000 bits 80,000 \u00f7 8 = 10,000 bytes

Answer: 10,000 bytes.

7

Calculate the file size, in bytes, of a 640 × 480 pixel image with 24-bit colour depth.

Show full working
640 × 480 × 24 = 7,372,800 bits 7,372,800 \u00f7 8 = 921,600 bytes

Answer: 921,600 bytes.

8

A 10 × 10 pixel image uses 1-bit colour depth. Calculate the file size in bytes, rounding appropriately.

Show full working
10 × 10 × 1 = 100 bits 100 \u00f7 8 = 12.5 bytes

You can't store half a byte, so round up: 13 bytes.

C

Trade-offs

Reasoning about how changes to resolution and colour depth affect file size.

9

Explain the effect on file size of doubling an image's colour depth, keeping the resolution the same.

Show model answer

File size doubles, since file size is directly proportional to colour depth (file size = width × height × colour depth, and only colour depth has changed).

10

Explain the effect on file size of doubling both the width and height of an image, keeping colour depth the same.

Show model answer

File size increases by a factor of 4, not 2. The total number of pixels is width × height; doubling both factors in that multiplication multiplies the result by 2 × 2 = 4.

11

A user wants to reduce an image's file size without reducing its resolution. Suggest one way to do this.

Show model answer

Any of the following is acceptable: reduce the colour depth (fewer bits per pixel, at the cost of fewer available colours), or apply compression (lossy or lossless, as covered in the previous lesson) to the image data.

D

Exam-style question

A longer, multi-part question.

12

A digital camera captures photos at a resolution of 4000 × 3000 pixels, using 24-bit colour depth.

(a) Calculate the uncompressed file size of one photo, in bytes and in megabytes.
(b) The camera also offers a "thumbnail" mode at 400 × 300 pixels, using the same colour depth. Calculate the thumbnail's file size in bytes.
(c) Explain why the full-size photo is normally saved as a compressed JPEG file rather than in this uncompressed format.

Show model answer

(a)

4000 × 3000 × 24 = 288,000,000 bits 288,000,000 \u00f7 8 = 36,000,000 bytes = 36 MB

(b)

400 × 300 × 24 = 2,880,000 bits 2,880,000 \u00f7 8 = 360,000 bytes

(c) At 36MB per photo, uncompressed images would fill up storage very quickly and take much longer to transfer. JPEG applies lossy compression, discarding some detail the human eye is unlikely to notice, to achieve a much smaller file — typically a fraction of the uncompressed size — while remaining visually very close to the original.
