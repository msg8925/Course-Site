D

BCD vs pure binary

Compare how many bits each representation needs for the same number.

10

How many bits does BCD need to encode the 3-digit number 456?

Show full working

3 digits × 4 bits each = 12 bits.

11

Explain why BCD generally needs more bits than pure binary to represent the same number.

Show model answer

Each BCD nibble only ever uses 10 of its 16 possible bit patterns (0000–1001), wasting the remaining six (1010–1111) on every single digit. Pure binary uses every possible bit pattern to represent the number as a whole, so it doesn't waste any combinations — making it more compact for the same value. For example, 456 needs 12 bits in BCD but only 9 bits in pure binary.

E

Exam-style question

A longer, multi-part question.

12

A digital kitchen scale displays weight as a 4-digit decimal readout (e.g. 1 234 g), with each digit driven by its own display segment.

(a) Encode the reading 1 234 in BCD.
(b) Explain why BCD is a more sensible choice than pure binary for this scale's internal circuitry.
(c) State how many bits BCD uses for this reading, and how many bits pure binary would use for the same value.

Show model answer

(a) 1 → 0001, 2 → 0010, 3 → 0011, 4 → 0100. Answer: 0001 0010 0011 0100.

(b) The scale needs to drive four separate digit displays. With BCD, each display's segments can be looked up directly from its own 4-bit nibble; with pure binary, the whole number would first need converting back into separate digits before any of them could be displayed — extra work the circuit doesn't need to do if it uses BCD from the start.

(c) BCD: 4 digits × 4 bits = 16 bits. Pure binary: 1234 in binary is 10011010010, which is 11 bits.
