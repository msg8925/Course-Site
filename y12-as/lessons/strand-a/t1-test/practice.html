Exam-style questions

A 30-second stereo recording is sampled at 22,050 Hz using 8-bit resolution. Calculate the file size in KiB, then explain one way the file size could be reduced, and one drawback of doing so.

Reveal model answer

File size: 22,050 × 8 × 30 × 2 = 10,584,000 bits = 1,323,000 bytes ≈ 1291.99 KiB.

Reducing it: lowering the sample rate, the bit depth, or recording in mono instead of stereo would all reduce the file size. Drawback: any of these reduces the accuracy of the digital representation — a lower sample rate captures the waveform less often (risking audible distortion of higher frequencies), and a lower bit depth allows fewer possible amplitude levels per sample (increasing quantisation noise). Recording in mono discards the stereo (left/right) separation entirely.

A student claims: "947 in BCD is shorter than 947 in pure binary." Are they correct? Justify your answer by giving both representations.

Reveal model answer

The student is incorrect. 947 in BCD is 1001 0100 0111 — 12 bits (3 digits × 4 bits each). 947 in pure binary is 1110110011 — only 10 bits. Pure binary is actually shorter here, because BCD allocates a full 4 bits to every digit regardless of whether that digit needs all 4 bits to represent it (e.g. representing 0–9 in 4 bits wastes the 6 unused patterns 1010–1111 in every nibble), whereas pure binary uses the minimum bits needed for the whole number at once.
