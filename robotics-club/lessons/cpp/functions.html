Functions

Section focus: C/C++ Fundamentals — Lesson 1.6  |  Duration: ~45 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain what a function is and why breaking code into functions is useful
  • Write a function that accepts inputs (parameters) and gives back an output (a return value)
  • Call the same function multiple times with different inputs
  • Explain the difference between a function that returns a value and one that doesn't
Real-world analogy: A function is like a recipe card for one specific task — say, "make a cup of tea." Once that card exists, you don't re-explain the whole process every time you want tea; you just say "make tea" and hand over what varies (how many sugars). The recipe card is written once and reused as many times as needed, with different details each time if necessary.

1. The Problem Functions Solve

Imagine you need to square a number (multiply it by itself) in several different places in your program. Without functions, you'd repeat the same calculation everywhere you needed it. If you ever wanted to change how squaring worked, you'd need to find and update every copy. A function lets you write that logic once, give it a name, and reuse it anywhere.

2. Your First Function

#include <iostream>

int square(int number) {
    return number * number;
}

int main() {
    std::cout << square(4) << std::endl;
    std::cout << square(7) << std::endl;
    return 0;
}

This prints 16 then 49. Notice square is written once, above main(), but called (used) twice inside it, each time with a different input.

3. Breaking Down a Function's Parts

    return number * number;
}
PartExampleMeaning
Return typeint (before the name)The type of value this function will hand back. Use void if it doesn't return anything.
NamesquareWhat you'll call the function by — same naming rules as variables.
Parameters(int number)The inputs the function needs to do its job — variables that only exist inside the function.
Return statementreturn number * number;Sends a value back to wherever the function was called from, and immediately ends the function.

4. Functions That Don't Return Anything

Not every function needs to hand back a value — sometimes you just want it to do something, like printing a message:

#include <iostream>

void greet(std::string name) {
    std::cout << "Hello, " << name << "!" << std::endl;
}

int main() {
    greet("Maya");
    greet("Arun");
    return 0;
}

void as the return type means "this function doesn't send anything back" — it simply does its job (printing, in this case) and finishes.

5. Multiple Parameters

Functions can accept more than one input, separated by commas:

#include <iostream>

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 3);
    std::cout << "5 + 3 = " << result << std::endl;
    return 0;
}
Why bother capturing the result in a variable? int result = add(5, 3); runs add(5, 3), gets back 8, and stores it in result so it can be used later — printed, compared, or passed into another function. You could also skip the variable and write std::cout << add(5, 3); directly if you only need the value once.

6. Why This Matters for Arduino

You've actually been using functions since your very first program — main() is a function. On the Arduino, you'll soon meet two special functions, setup() and loop(), that follow exactly the same rules you've just learned; the Arduino environment simply calls them automatically rather than you calling them yourself. Writing your own functions (like readLeftSensor() or stopMotors()) will make your vehicle's code dramatically easier to read compared to one giant block of instructions.

Try it yourself:
  1. Write a function isEven(int number) that returns true if a number is even and false if it's odd (hint: look up the % modulo operator, which gives the remainder of a division).
  2. Write a void function called printLine() that prints a row of 20 dashes, and call it a few times in main() to separate other output visually.
  3. Write a function int max(int a, int b) that returns whichever of the two numbers is larger, using an if-statement from Lesson 1.3.
  4. Challenge: write a function that takes an array and its size as parameters (e.g. int sumArray(int arr[], int size)) and returns the total of all its values, reusing your loop knowledge from Lesson 1.4.
