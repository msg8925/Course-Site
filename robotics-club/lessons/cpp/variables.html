Variables and Data Types

Section focus: C/C++ Fundamentals — Lesson 1.2  |  Duration: ~45 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain what a variable is and why programs need them
  • Declare variables of the most common C++ data types
  • Explain why C++ needs to know a variable's type in advance
  • Read and change a variable's value while a program runs
Real-world analogy: A variable is like a labelled box. The label (the variable's name) never changes, but what's inside the box can — you can open it, look at the contents, replace them, or use them elsewhere. Crucially, in C++, each box also has a fixed size and shape stamped on it before you ever put anything in — a box built for whole numbers can't suddenly hold a sentence of text.

1. Declaring Your First Variable

To create a variable in C++, you state its type, give it a name, and (usually) an initial value:

int age = 13;

This creates a box named age, built specifically to hold whole numbers, currently containing the value 13. Try it inside a full program:

#include <iostream>

int main() {
    int age = 13;
    std::cout << "Age is: " << age << std::endl;
    return 0;
}

2. The Most Common Data Types

C++ has several built-in types, each suited to a different kind of data:

TypeHoldsExample
intWhole numbers (positive or negative)int score = 100;
floatDecimal numbersfloat temperature = 36.6;
charA single characterchar grade = 'A';
boolTrue or false onlybool isOn = true;
std::stringText (a sequence of characters)std::string name = "Maya";
A small but important detail: a single character in char uses single quotes ('A'), while text in std::string uses double quotes ("Maya"). Mixing these up is a very common early mistake that produces a confusing error message.
Why does C++ need to know the type in advance? Under the hood, the computer reserves a specific-sized chunk of memory for each variable, and that size depends entirely on the type — an int and a char physically take up different amounts of space in memory. Because C++ decides this before the program even runs, it can catch a whole category of mistakes early (like accidentally treating text as a number) rather than crashing unpredictably later. This is different from some other languages (like Python) that decide a variable's type automatically as the program runs — neither approach is "better," but it's why C++ code looks the way it does.

3. Changing a Variable's Value

Unlike a mathematical constant, a variable's contents can change while the program runs — that's the entire point of the name "variable":

#include <iostream>

int main() {
    int score = 0;
    std::cout << "Starting score: " << score << std::endl;

    score = 10;
    std::cout << "After scoring: " << score << std::endl;

    score = score + 5;  // take the current value and add 5
    std::cout << "After bonus: " << score << std::endl;

    return 0;
}

That third line is worth pausing on: score = score + 5; looks like nonsense as a maths equation (nothing equals itself plus 5), but it's not maths — it's an instruction. It means "work out score + 5 using the box's current contents, then put that new result back into the same box."

4. Naming Variables Well

C++ gives you freedom to name variables almost anything, but a few rules and habits matter:

RuleExample
Must start with a letter or underscore, not a numberint 2ndPlace is invalid; int secondPlace is fine
No spaces allowedint high score is invalid; int highScore is fine
Case-sensitivescore and Score are treated as two completely different variables
Choose meaningful names (a habit, not a rule)int x = 13; works, but int studentAge = 13; is far easier for you — and others — to understand later
Try it yourself:
  1. Create variables for your name (std::string), your age (int), and your favourite letter grade (char), then print all three in one sentence using std::cout.
  2. Create an int variable, print it, change its value, then print it again — confirm the value actually changed.
  3. Try assigning text to an int variable (e.g. int number = "hello";) on purpose. Read the compiler error — what is it telling you?
  4. Challenge: create two int variables representing two scores, and print their sum without creating a third variable to store it.
