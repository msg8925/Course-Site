Loops: for and while

Section focus: C/C++ Fundamentals — Lesson 1.4  |  Duration: ~45 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain why repeating code by copy-pasting is a problem worth solving
  • Write a for loop and explain its three parts
  • Write a while loop and know when to prefer it over a for loop
  • Recognise and avoid an infinite loop
Real-world analogy: A loop is like a coach saying "run ten laps." The coach doesn't write out ten separate instructions ("run lap 1," "run lap 2," ...) — they give one instruction with a repeat count, and you keep going until the condition ("ten laps") is satisfied. A loop is a program's way of saying "keep doing this until I tell you to stop," instead of writing the same instruction over and over by hand.

1. The Problem Loops Solve

Imagine printing the numbers 1 to 5. Without loops, you'd have to write this:

std::cout << 1 << std::endl;
std::cout << 2 << std::endl;
std::cout << 3 << std::endl;
std::cout << 4 << std::endl;
std::cout << 5 << std::endl;

This works, but it doesn't scale — printing 1 to 1000 this way would take 1000 lines. Worse, if you needed to change what happens on each line, you'd have to edit every single one. Loops solve exactly this problem.

2. The For Loop

A for loop is the right tool when you know roughly how many times you want to repeat something:

#include <iostream>

int main() {
    for (int i = 1; i <= 5; i++) {
        std::cout << i << std::endl;
    }
    return 0;
}

This prints 1 through 5 — five lines of output from three lines of code. A for loop has three parts, separated by semicolons, all sitting in the parentheses:

PartExampleMeaning
Starting pointint i = 1Runs once, right at the start — creates a counter variable
Conditioni <= 5Checked before every repeat — the loop continues only while this is true
Updatei++Runs at the end of every repeat — i++ means "add 1 to i"
Why i? Single-letter names like i (short for "index") are a long-standing convention specifically for loop counters — it's one of the few places short names are considered good style rather than lazy, precisely because their role is so immediately obvious from context.

3. The While Loop

A while loop is the right tool when you don't know in advance how many repeats you'll need — you just know the condition that should keep it going:

#include <iostream>

int main() {
    int count = 1;

    while (count <= 5) {
        std::cout << count << std::endl;
        count = count + 1;
    }

    return 0;
}

This produces identical output to the for loop above. The difference is really about intent: a for loop bundles "start, condition, update" neatly together, which makes counted repeats easy to read at a glance; a while loop just keeps checking a condition, which suits situations where the ending condition depends on something happening during the loop, not a fixed count.

The infinite loop: a while loop only stops when its condition becomes false. If you forget to update whatever the condition depends on (like forgetting count = count + 1; above), the condition never changes, and the loop runs forever — usually freezing your program. If your program ever seems to "hang" and never finish, an infinite loop is the first thing to suspect. Most online compilers have a stop or timeout button for exactly this situation.

4. Choosing Between For and While

Use...When...
forYou know how many times to repeat (a fixed count, or looping through a list of a known size)
whileYou're repeating "until something happens," and you don't know in advance how long that will take
Looking ahead: when your Arduino is running, its loop() function is itself an infinite loop by design — it repeats forever, for as long as the board has power, which is exactly what you want for a robot that needs to keep checking its sensors continuously. The for and while loops you're learning now will typically live inside that always-running loop(), handling specific repeated tasks such as reading several sensors in sequence.
Try it yourself:
  1. Write a for loop that prints the numbers 10 down to 1 (counting backward).
  2. Write a for loop that prints only the even numbers between 1 and 20.
  3. Write a while loop that keeps doubling a starting value of 1 until it exceeds 1000, printing each value along the way.
  4. Challenge: combine loops with the if-statements from the last lesson — print every number from 1 to 30, but print "Fizz" instead of the number if it's divisible by 3.
