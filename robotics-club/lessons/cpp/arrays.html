Arrays

Section focus: C/C++ Fundamentals — Lesson 1.5  |  Duration: ~45 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain what an array is and why it's more useful than many separate variables
  • Declare an array, and read or change values inside it
  • Explain why arrays are indexed starting at 0, not 1
  • Use a for loop to process every item in an array
Real-world analogy: An array is like a row of numbered lockers, all bolted together in a line. Each locker holds one item, every locker is the same size, and you find any item instantly if you know its locker number — no need to search through every locker one by one. The "locker number" in code is called an index.

1. The Problem Arrays Solve

Imagine storing five test scores. Without arrays, you might write:

int score1 = 85;
int score2 = 92;
int score3 = 78;
int score4 = 90;
int score5 = 88;

This works for five scores, but what about fifty? Or what if you wanted to find the average — you'd need to write out every single variable name by hand in the calculation. An array stores a whole collection of values of the same type under a single name.

2. Declaring an Array

int scores[5] = {85, 92, 78, 90, 88};

This creates one array named scores, holding five int values. Picture it as five connected lockers:

850
921
782
903
884

The numbers underneath are each value's index — its position in the array.

Arrays count from 0, not 1. This trips up almost everyone at first. The first item is at index 0, not 1 — so in the array above, scores[0] is 85, and the last item, 88, is at index 4, not 5. For an array of size 5, valid indexes are always 0 through size - 1. Trying to access scores[5] is a classic bug — that locker doesn't exist, and C++ often won't stop you from asking for it, leading to unpredictable behaviour rather than a clear error.

3. Reading and Changing Values

#include <iostream>

int main() {
    int scores[5] = {85, 92, 78, 90, 88};

    std::cout << "First score: " << scores[0] << std::endl;
    std::cout << "Third score: " << scores[2] << std::endl;

    scores[2] = 100;  // change the third score
    std::cout << "Updated third score: " << scores[2] << std::endl;

    return 0;
}

4. Looping Through an Array

Arrays and for loops from the last lesson are a natural pair — instead of writing out five separate std::cout lines, a loop can visit every locker automatically:

#include <iostream>

int main() {
    int scores[5] = {85, 92, 78, 90, 88};

    for (int i = 0; i < 5; i++) {
        std::cout << "Score " << i << ": " << scores[i] << std::endl;
    }

    return 0;
}

Notice the loop's condition is i < 5, not i <= 5 — this is exactly the "counting from 0" rule from above. With 5 items at indexes 0–4, the loop needs to stop before reaching index 5.

5. A Practical Example: Finding the Total and Average

#include <iostream>

int main() {
    int scores[5] = {85, 92, 78, 90, 88};
    int total = 0;

    for (int i = 0; i < 5; i++) {
        total = total + scores[i];
    }

    float average = total / 5.0;  // 5.0, not 5, to get a decimal result

    std::cout << "Total: " << total << std::endl;
    std::cout << "Average: " << average << std::endl;

    return 0;
}
Looking ahead: once you're wiring up multiple sensors on the line-following vehicle, an array is the natural way to store several sensor readings at once (e.g. int sensorReadings[5]; for five line sensors), and a for loop is how you'll read all of them in a few lines instead of five nearly-identical ones.
Try it yourself:
  1. Create an array of 6 of your own choosing (favourite numbers, ages of family members, anything) and print every value using a for loop.
  2. Write a loop that finds and prints the largest value in an array of your choosing.
  3. Deliberately access one index past the end of an array (e.g. scores[5] on a 5-item array) and print it. What happens? Is it a clear error, or something stranger?
  4. Challenge: write a loop that counts how many values in an array are above a certain threshold (e.g. how many scores are 90 or above), combining what you learned about if-statements with arrays.
