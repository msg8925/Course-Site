Reading Resistor Values

Section focus: Electronics Fundamentals — Lesson 2.2  |  Duration: ~45 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain what resistance is and why circuits need it
  • Read a resistor's value from its coloured bands
  • Explain what the tolerance band tells you
  • Verify a resistor's value using a multimeter
Real-world analogy: Resistance is like a narrow section in a garden hose — it doesn't stop the water (current) entirely, but it restricts how much flows through, protecting whatever is downstream from too strong a flow. A resistor is a component built specifically to add a known, controlled amount of that restriction to a circuit.

1. Why Resistors Matter

Many components — LEDs especially — can be damaged by too much current flowing through them. A resistor placed in series limits that current to a safe level. You've already used this in nearly every lesson so far without necessarily knowing exactly how its value was chosen — this lesson fills in that gap.

2. The Colour Band System

Most resistors are too small to print a number on clearly, so their value is encoded instead as a series of coloured bands. A standard 4-band resistor reads like this:

Figure 1: Four bands — two digits, a multiplier, and a tolerance — read left to right, starting from the band closest to one end.

3. Working Through the Example

The resistor in Figure 1 reads Brown, Red, Black, Gold:

  • Brown = 1 (first digit)
  • Red = 2 (second digit) → so far, "12"
  • Black = ×1 (multiplier) → 12 × 1 = 12Ω
  • Gold = ±5% tolerance

So this is a 12Ω resistor, accurate to within 5% of that value. This is actually an unusually low value for the kind of circuits in this club — the 220Ω and 10kΩ resistors you've used constantly in earlier lessons follow exactly the same reading process, just with different colours.

Working example: 220Ω. This common value reads Red, Red, Brown, Gold: Red=2, Red=2 → "22", Brown = ×10 → 22 × 10 = 220Ω. Recognising this exact band sequence will save you time, since it's the resistor you'll reach for most often when protecting an LED.
Which end do you start reading from? The tolerance band (usually gold or silver) is typically spaced slightly apart from the others, near one end — that gap tells you which end to start reading from. If you're ever unsure, or the resistor is too small to tell confidently, a multimeter is the reliable fallback (see below) — reading it backwards gives a nonsense multiplier value that's usually obviously wrong once calculated.

4. Verifying with a Multimeter

If you have access to a multimeter:

  1. Set it to resistance mode (usually marked with the Ω symbol)
  2. Touch one probe to each leg of the resistor (orientation doesn't matter for resistance)
  3. Read the displayed value and compare it to what you calculated from the colour bands

This is good practice generally: trust your calculation, but verify it when the result matters and a meter is available.

Try it yourself:
  1. Find three different resistors from your kit and read their values from the colour bands alone.
  2. If a multimeter is available, verify each of your three readings.
  3. Work out what colour bands a 1kΩ resistor would have (hint: 1,000Ω).
  4. Challenge: find the 220Ω and 10kΩ resistors specifically from your kit (used constantly in earlier Arduino lessons) and confirm you can identify their band sequence at a glance without recalculating each time.
