Controlling an LED with a Potentiometer

Session focus: Analog Input — reading a potentiometer to control an LED  |  Duration: ~60 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain how a potentiometer produces a variable voltage
  • Wire a potentiometer and LED to an Arduino on a breadboard
  • Read an analog value with analogRead() and understand its 0–1023 range
  • Convert that reading into a PWM value to smoothly control an LED's brightness
Real-world analogy: A potentiometer is exactly like a dimmer switch on a wall light, or the volume knob on an old radio. Turning it doesn't switch anything fully on or off — it smoothly increases or decreases a value, letting the Arduino "hear" exactly how far round the knob has been turned.

2. Understanding the Potentiometer

A potentiometer has three pins. The two outer pins connect across a fixed resistive strip; the middle pin (the "wiper") slides along that strip as you turn the knob, picking off a voltage somewhere between the two ends.

PinFunctionConnects To
Outer pin 1Fixed end of resistive trackArduino 5V
Middle pin (wiper)Variable voltage outputArduino analog input (e.g. A0)
Outer pin 2Fixed end of resistive trackArduino GND

With one end at 5V and the other at GND, the wiper outputs somewhere between 0V and 5V depending on the knob's position — this is exactly the kind of signal an Arduino's analog input pins are designed to read.

Why an analog pin, not a digital one: Digital pins can only see HIGH or LOW — fully on or fully off. A potentiometer's whole purpose is to produce something in between, so it must connect to one of the Arduino's analog input pins (A0–A5), which can measure a range of voltages, not just two states.

3. Understanding the LED Circuit

The LED and its 220Ω resistor connect in series between a digital pin and GND. The resistor limits current through the LED so it doesn't burn out — this doesn't change with this lesson, but it's worth re-stating each time an LED appears in a circuit.

Figure 1: The potentiometer's wiper feeds a variable voltage into A0; the Arduino uses that reading to set the LED's brightness on Pin 9.

4. Step-by-Step Instructions

1Wire the potentiometer

  • One outer pin → Arduino 5V
  • Other outer pin → Arduino GND
  • Middle pin (wiper) → Arduino A0

2Wire the LED

  • LED's longer leg (anode) → 220Ω resistor → Arduino Pin 9
  • LED's shorter leg (cathode) → Arduino GND

3Write the program

// Potentiometer-Controlled LED Brightness
const int potPin = A0;
const int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int potValue = analogRead(potPin);      // reads 0 to 1023
  int brightness = map(potValue, 0, 1023, 0, 255); // scale to 0-255 for PWM

  analogWrite(ledPin, brightness);

  Serial.print("Pot: ");
  Serial.print(potValue);
  Serial.print("  Brightness: ");
  Serial.println(brightness);

  delay(50);
}

4Upload and test

Upload the code and turn the potentiometer's knob. The LED should smoothly dim and brighten as you turn it. Open the Serial Monitor (9600 baud) to see the raw and scaled values changing alongside the LED.

Why the map() function is needed: analogRead() gives a value from 0–1023 (the Arduino's analog-to-digital converter has more precision than we need here), but analogWrite() for PWM brightness only accepts 0–255. map() rescales one range onto the other automatically.

Troubleshooting

  • LED doesn't light at all: check the LED's orientation — the longer leg (anode) must go toward the resistor/Pin 9 side, not GND.
  • Turning the knob does nothing: check the wiper (middle pin) is connected to A0, not one of the outer pins.
  • Serial Monitor shows numbers stuck at 0 or 1023: check both outer pins of the potentiometer are connected — one to 5V, one to GND — not both to the same rail.
  • LED flickers instead of dimming smoothly: make sure Pin 9 is a PWM-capable pin (marked with a "~" symbol on most Arduino boards).

5. Why This Matters

This is the analog counterpart to everything you've done with digital HIGH/LOW signals so far — instead of a simple on/off input, you're now reading a continuous range and using it to drive a continuous output. The same pattern (read analog value → map it → apply it) will reappear whenever you use a sensor that reports a range of values rather than a simple digital signal.

Try it yourself:
  1. Reverse the mapped range with map(potValue, 0, 1023, 255, 0) so turning the knob one way now dims instead of brightens. What changed?
  2. Add a second LED on a different PWM pin that gets brighter as the first one gets dimmer.
  3. Challenge: instead of controlling brightness, use the mapped value to control the blink speed of the LED (map the potentiometer to a delay time between 50ms and 1000ms).
