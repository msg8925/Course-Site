Controlling a DC Motor with Arduino

Session focus: Motors — small DC motor via motor driver  |  Duration: ~60 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain why a DC motor cannot be connected directly to an Arduino pin
  • Wire a DC motor to an Arduino using an L298N motor driver module
  • Write a program that controls motor direction and speed
  • Compare how a DC motor's continuous spin differs from a servo's fixed-angle positioning
Real-world analogy: If a servo is like a clock hand that points at a specific number, a DC motor is like a bicycle wheel — it just spins, as fast or slow as you let it, for as long as you let it, in whichever direction you choose. It has no idea what "angle" it's at; it only knows "spin" or "stop."
Why we need a motor driver: An Arduino pin can only safely supply a tiny amount of current (about 20mA). A DC motor, even a small one, can pull far more than that when it starts spinning or slows down — enough to damage the Arduino if wired directly. A motor driver module (we'll use the L298N) sits between the Arduino and the motor: the Arduino sends it small, safe signals, and the driver uses a separate, stronger power supply to actually drive the motor. Never wire a DC motor straight into an Arduino pin.

2. Understanding the L298N Driver

The L298N takes a few signal pins from the Arduino and uses them to control a much bigger current flowing from the external battery pack to the motor. For one motor, we mainly use three connections:

L298N PinFunctionConnects To
IN1Direction control AArduino Pin 8
IN2Direction control BArduino Pin 9
ENASpeed control (PWM)Arduino Pin 10
OUT1 / OUT2Motor terminalsThe two motor wires (either way round)
+12V / GND (power side)Motor powerExternal battery pack
GND (logic side)Common groundArduino GND — must be connected

How direction works: IN1 HIGH + IN2 LOW spins one way; IN1 LOW + IN2 HIGH spins the other way; both LOW (or both HIGH) stops the motor. ENA's PWM value (0–255) controls how fast it spins.

3. Step-by-Step Instructions

1Wire the driver to the Arduino

  • IN1 → Arduino Pin 8
  • IN2 → Arduino Pin 9
  • ENA → Arduino Pin 10
  • GND (logic side) → Arduino GND

2Wire the motor and power

  • Connect the two motor wires to OUT1 and OUT2 (either order — it only affects which direction counts as "forward")
  • Connect the external battery pack's positive and negative leads to the driver's power input (+12V and GND)

Leave the battery pack switched off (or disconnected) until wiring is fully checked.

3Write the program

// DC Motor Control Example
const int IN1 = 8;
const int IN2 = 9;
const int ENA = 10;

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
}

void loop() {
  // Spin forward at full speed for 2 seconds
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, 255);   // speed: 0 (stop) to 255 (full speed)
  delay(2000);

  // Stop for 1 second
  analogWrite(ENA, 0);
  delay(1000);

  // Spin backward at half speed for 2 seconds
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  analogWrite(ENA, 130);
  delay(2000);

  // Stop for 1 second
  analogWrite(ENA, 0);
  delay(1000);
}

4Power on and test

Connect the USB cable, upload the code, then switch on the external battery pack. The motor should spin forward fast, stop, spin backward more slowly, stop, and repeat.

Troubleshooting

  • Motor doesn't spin at all: check the battery pack is switched on and its wires are firmly connected — this is the most common issue.
  • Motor buzzes but doesn't turn: check ENA is receiving a PWM value above 0; a very low value may not be enough to overcome friction.
  • Motor only spins one direction regardless of code: double check IN1 and IN2 are wired to the pin numbers written in the code.
  • Arduino resets or behaves oddly when motor starts: this is usually a shared/weak ground — make sure the logic GND is connected between Arduino and driver.

Try it yourself:
  1. Change the speed value in analogWrite(ENA, ...) and observe how the motor's behaviour changes.
  2. Rewrite the code so the motor gradually speeds up from 0 to 255 instead of jumping straight to full speed.
  3. Challenge: combine this with the servo tutorial — write a program where a servo points in a direction while the DC motor drives forward, as a first step toward the line-following vehicle's steering and drive system.
