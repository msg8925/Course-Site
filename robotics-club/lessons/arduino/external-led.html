Controlling an External LED on a Breadboard

Section focus: Arduino Programming — Lesson 3.4  |  Duration: ~40 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Wire an LED and resistor to an Arduino pin, rather than a battery
  • Control that LED entirely through code
  • Explain what changed, and what stayed the same, compared to the battery-powered version from Lesson 2.4

1. What's Actually Different from Lesson 2.4?

In Lesson 2.4, you built a working LED circuit powered directly by a battery — always on, with no way to control it. The circuit itself doesn't change at all here; the only difference is where the power comes from. Instead of a battery's fixed 5V, one Arduino pin now plays that role — and because it's controlled by code, you can turn it on, off, or blink it in any pattern you like.

Figure 1: Same LED + resistor circuit as Lesson 2.4 — only the power source has changed.

2. Step-by-Step Instructions

1Wire the circuit

  • LED's longer leg (anode) → 220Ω resistor → Arduino Pin 7
  • LED's shorter leg (cathode) → Arduino GND

2Write the program

void setup() {
    pinMode(7, OUTPUT);
}

void loop() {
    digitalWrite(7, HIGH);  // LED on
    delay(500);
    digitalWrite(7, LOW);   // LED off
    delay(500);
}

3Upload and test

Upload the code — your external LED should now blink twice per second, controlled entirely by the Arduino.

Troubleshooting

  • LED doesn't light at all: check its orientation first (the most common issue, exactly as in Lesson 2.4), then confirm the resistor and LED are in the same breadboard column as the Arduino pin's wire.
  • LED stays on solidly, doesn't blink: check you're using digitalWrite(), not accidentally leaving the pin permanently HIGH somewhere in your code.
Looking ahead: this exact wiring pattern — a pin, a resistor, an LED, and GND — is the electrical backbone behind the RGB LED (three of these at once), the 7-segment display (seven of these at once, plus a lookup table), and the status LEDs you might add to your line-following vehicle later.
Try it yourself:
  1. Change the blink pattern to mimic Morse code for a short word of your choice (short delay = dot, long delay = dash).
  2. Wire a second LED on a different pin, and make the two LEDs blink alternately (one on while the other is off).
  3. Challenge: using a for loop, make the LED "pulse" a fixed number of quick blinks whenever the program starts, before settling into its regular blink pattern.
