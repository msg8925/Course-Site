Controlling a Stepper Motor with Arduino

Session focus: Motors — stepper motor via ULN2003 driver board  |  Duration: ~60 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain what makes a stepper motor different from a servo or a DC motor
  • Wire a stepper motor and ULN2003 driver board to an Arduino
  • Write a program that rotates the motor a precise number of steps, in either direction
  • Identify which of the board's pins matter for this project and which don't
Real-world analogy: If a DC motor is a bicycle wheel that just spins, a stepper motor is more like the second hand of a mechanical watch — it moves in small, precise, equally-sized "ticks" (steps), and it always knows exactly how many ticks it has moved. This makes it perfect for tasks where exact positioning matters, like opening a camera shutter by a set amount or driving a 3D printer's axis.

2. Understanding Your Driver Board

What you've described is the standard 28BYJ-48 driver board, built around the ULN2003AN chip. That chip's job is similar to the L298N from the DC motor lesson: it takes small, safe signals from the Arduino and uses them to switch larger currents to the motor's coils. A few things about the specific pins you mentioned:

Label on BoardWhat It Actually Does
Motor connector slotPlugs directly into the 5-wire stepper motor connector — there's usually only one way it fits
LEDs A, B, C, DEach lights up when its matching coil is energised — useful for watching the step sequence happen in real time
IN1, IN2, IN3, IN4The four pins that actually control the motor's four coils — these are the ones you'll wire to the Arduino
IN5, IN6, IN7 (if present)Spare channels on the ULN2003AN chip, broken out for driving other things (LEDs, relays, buzzers). Not used for this motor — the stepper only needs IN1–IN4
+ / – (or VCC / GND)Power for the motor coils — connect to Arduino 5V and GND
About the "IN1 to IN7" pins: The ULN2003AN chip at the heart of this board actually has seven identical driver channels inside it — that's simply how the chip is designed, for general-purpose use in relays, lamps, and other loads. Your board has broken all seven out to pins, but only four of them (IN1–IN4) are wired to the stepper motor's coils. The rest are unused for this project — leave them disconnected.

Figure 1: Arduino Pins 8–11 control coil switching via IN1–IN4; 5V and GND power the board. The motor plugs straight into the board's connector.

3. Step-by-Step Instructions

1Connect the motor to the driver board

Plug the stepper motor's connector into the board's socket — it's keyed, so it will only go in one way round.

2Wire the driver board to the Arduino

  • IN1 → Arduino Pin 8
  • IN2 → Arduino Pin 9
  • IN3 → Arduino Pin 10
  • IN4 → Arduino Pin 11
  • + (VCC) → Arduino 5V
  • – (GND) → Arduino GND

Leave IN5, IN6, and IN7 disconnected — they're not part of this circuit.

3Write the program

Arduino's built-in Stepper library handles the coil-switching sequence for you. Note the slightly unusual pin order in the code below (8, 10, 9, 11) — this matches the coil firing order inside the motor, not the physical IN1–IN4 order, and is a very common gotcha worth flagging to students.

// Stepper Motor Example (28BYJ-48 + ULN2003)
#include <Stepper.h>

const int stepsPerRevolution = 2048;  // steps for one full turn of this motor

// Note the pin order: IN1, IN3, IN2, IN4
Stepper myStepper(stepsPerRevolution, 8, 10, 9, 11);

void setup() {
  myStepper.setSpeed(10);  // speed in RPM
}

void loop() {
  myStepper.step(stepsPerRevolution);   // one full rotation clockwise
  delay(1000);

  myStepper.step(-stepsPerRevolution);  // one full rotation counter-clockwise
  delay(1000);
}

4Upload and observe

Upload the code. Watch the four LEDs (A, B, C, D) on the driver board — you should see them light up in a rolling sequence as the motor turns. The motor should complete one slow full rotation clockwise, pause, then rotate back counter-clockwise.

A note on current draw: Like the DC motor, a stepper motor draws current continuously while holding position, not just while moving. For this small motor, USB power is fine, but if you scale up to a bigger stepper later, it will need its own external power supply, wired similarly to the DC motor lesson.

Troubleshooting

  • Motor vibrates or buzzes but doesn't turn: almost always a pin-order issue — double check the code uses 8, 10, 9, 11 and not the "obvious" 8, 9, 10, 11.
  • Nothing happens, no LEDs light up: check + and – are connected to 5V and GND.
  • Motor turns the wrong direction: swap the sign of the step count, e.g. use a negative number.
  • Motor is very slow or noisy: try adjusting setSpeed() — very high or very low values can both cause missed steps.

Try it yourself:
  1. Change stepsPerRevolution in the step commands to a smaller number, e.g. 512. What fraction of a full turn does the motor make?
  2. Change setSpeed() to a much higher or lower value and note what happens to smoothness and reliability.
  3. Challenge: write a program that moves the motor exactly a quarter-turn, pauses, then continues in quarter-turns until it completes a full rotation — printing the step count to the Serial Monitor after each move.
