Controlling a Servo Motor with Arduino

Session focus: Motors — micro servo (SG90)  |  Duration: ~60 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain what a servo motor is and how it differs from a normal DC motor
  • Correctly wire an SG90 micro servo to an Arduino
  • Write and upload a program that moves the servo to specific angles
  • Predict and test what happens when you change angle values in code
Real-world analogy: Think of the servo like a clock hand controlled by a tiny, very obedient hand. You don't tell it "spin forever" like a fan motor — you tell it exactly where to point (an angle between 0° and 180°), and it moves there and holds position, just like a clock hand pointing at a specific number.

2. Understanding the SG90 Servo

The SG90 has three wires, and getting them right is the single most important part of this lesson:

Wire ColourFunctionConnects To
Brown / BlackGround (GND)Arduino GND
RedPower (+5V)Arduino 5V
Orange / YellowSignal (PWM)Arduino digital pin (e.g. Pin 9)

Figure 1: Wiring the SG90 servo to an Arduino Uno — signal to Pin 9, power to 5V, ground to GND.

3. Step-by-Step Instructions

1Wire the servo

With the Arduino unplugged, connect the three servo wires using jumper wires:

  • Orange/yellow wire → Digital Pin 9
  • Red wire → 5V
  • Brown/black wire → GND

Double-check the order before powering on — a reversed connection won't usually damage the servo, but it also won't work.

2Open the Arduino IDE

Plug the Arduino into your computer with the USB cable. Open the Arduino IDE, and under Tools, check that the correct board and port are selected.

3Write the program

Type (or copy) the following code into a new sketch:

// Servo Sweep Example
#include <Servo.h>

Servo myServo;      // create a servo object

void setup() {
  myServo.attach(9); // attach servo signal wire to pin 9
}

void loop() {
  myServo.write(0);   // move to 0 degrees
  delay(1000);         // wait 1 second

  myServo.write(90);  // move to 90 degrees
  delay(1000);

  myServo.write(180); // move to 180 degrees
  delay(1000);
}

4Upload and test

Click Upload. Watch the servo — it should rotate smoothly to 0°, then 90°, then 180°, pausing for a second at each position, then repeat.

Troubleshooting

  • Servo doesn't move at all: check the signal wire is on the pin number written in attach(), and that GND is properly connected.
  • Servo jitters or twitches constantly: this usually means a weak or shared power connection — try powering the servo from an external 5V source for larger projects (not needed for a single SG90 on USB power).
  • Upload fails: check the correct board and port are selected under Tools.

4. Why This Matters

Servos are how robots point, grip, and steer. In our line-following vehicle project, a servo (or similar motor control) will later be responsible for tasks like steering direction or a mechanical arm — this exercise is the foundation for that.

Try it yourself:
  1. Change the delay time from 1000 to 200. What happens to the servo's movement?
  2. Add a new line to move the servo to 45 degrees, before it returns to 0.
  3. Challenge: use for loop logic to make the servo sweep smoothly from 0° to 180°, one degree at a time, instead of jumping between three fixed angles.
