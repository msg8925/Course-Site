Interfacing the 1602A LCD Display with Arduino

Session focus: Digital Output — character LCD display  |  Duration: ~60 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain what the 1602A display can and can't do
  • Wire the display to an Arduino, including setting up contrast
  • Write a program that prints text to specific positions on the screen
  • Display a live changing value (not just fixed text) on the screen
Real-world analogy: Think of the 1602A like an old digital alarm clock display, but for letters instead of just numbers — it has 2 rows of 16 character "boxes" each, and every box can show one letter, number, or symbol at a time. Unlike your phone screen, it can't draw pictures or use different fonts — only the fixed grid of characters it was built for.

If your display has a small blue "backpack" module soldered to the back with only 4 pins (GND, VCC, SDA, SCL): that's an I2C adapter, and it simplifies this whole lesson considerably — you'd only need 4 wires and the LiquidCrystal_I2C library instead. This lesson covers the standard 16-pin version; ask your teacher if you have the I2C version and need the adapted wiring.

2. Understanding the 1602A's Pins

The display has 16 pins, but for basic text output we only need to actually connect 10 of them:

PinFunctionConnects To
VSSGroundArduino GND
VDDPowerArduino 5V
V0Contrast controlPotentiometer wiper (middle pin)
RSRegister SelectArduino Pin 12
RWRead/WriteArduino GND (we only ever write, so this is tied to ground)
EEnableArduino Pin 11
D4–D7Data linesArduino Pins 5, 4, 3, 2
BLA / BLKBacklight power (anode / cathode)5V / GND (through a resistor on BLA if not built in)

Pins D0–D3 are left unconnected — we're using "4-bit mode," which needs only 4 data lines instead of 8, and is what the standard Arduino library expects.

Figure 1: The potentiometer sets contrast via V0; RS, E, and D4–D7 carry the actual character data.

3. Step-by-Step Instructions

1Wire the potentiometer for contrast

Connect the potentiometer's two outer pins to 5V and GND, and its middle pin (the wiper) to the LCD's V0 pin. You'll adjust this after powering on.

2Wire the LCD to the Arduino

  • VSS → GND, VDD → 5V
  • RW → GND
  • RS → Pin 12
  • E → Pin 11
  • D4, D5, D6, D7 → Pins 5, 4, 3, 2
  • Backlight BLA → 5V (through a resistor if not built in), BLK → GND

3Write the program

The LiquidCrystal library comes built into the Arduino IDE — no need to install anything extra.

// 1602A LCD Example
#include <LiquidCrystal.h>

// LiquidCrystal(RS, E, D4, D5, D6, D7)
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  lcd.begin(16, 2);          // 16 columns, 2 rows
  lcd.print("Hello, Club!");  // prints starting at top-left
}

void loop() {
  // nothing needed here for static text
}

4Upload and adjust contrast

Upload the code, then slowly turn the potentiometer. Somewhere in its range, "Hello, Club!" should appear clearly on the top row. If you see a row of solid black blocks, or nothing at all, keep adjusting — that's a contrast issue, not a wiring fault.

Troubleshooting

  • Screen shows solid black rectangles on one row: almost always the contrast potentiometer — turn it slowly through its full range.
  • Screen is blank, backlight is off: check power (VDD/VSS) and backlight (BLA/BLK) connections.
  • Screen is blank, backlight is on: check RS, E, and the four data pins match the numbers in LiquidCrystal lcd(...).
  • Garbled or wrong characters: double-check D4–D7 are wired in the same order as written in the code (5, 4, 3, 2).

4. Positioning Text and Showing Live Data

Most real uses need more than one fixed message — you'll want to control exactly where text appears, and update it based on changing data:

#include <LiquidCrystal.h>

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);
int count = 0;

void setup() {
  lcd.begin(16, 2);
  lcd.setCursor(0, 0);       // column 0, row 0 (top-left)
  lcd.print("Count:");
}

void loop() {
  lcd.setCursor(0, 1);       // column 0, row 1 (bottom row)
  lcd.print(count);
  lcd.print("   ");          // clears leftover digits from previous number
  count++;
  delay(500);
}

Note the trailing spaces after lcd.print(count) — without them, a shrinking number (e.g. going from 100 back down to 9) leaves old digits behind, since the LCD doesn't clear characters on its own.

5. Why This Matters

A display like this gives your circuit a way to communicate back to you without needing the Serial Monitor and a USB cable — essential once a project is untethered from a computer. In the vehicle build, this is exactly the kind of component you might use to show a live sensor reading, a status message, or a countdown during the competition.

Try it yourself:
  1. Print your name on the top row and "Robotics Club" on the bottom row.
  2. Make the count example count down from 10 to 0 instead of counting up forever.
  3. Challenge: combine this with the HC-SR04 lesson — display the live distance reading on the LCD instead of (or as well as) the Serial Monitor.
