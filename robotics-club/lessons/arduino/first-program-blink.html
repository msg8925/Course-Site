Your First Program: Blinking the Built-In LED

Section focus: Arduino Programming — Lesson 3.3  |  Duration: ~40 minutes

Learning Objectives

By the end of this session, you will be able to:

  • Explain the roles of setup() and loop() in every Arduino program
  • Write, upload, and run a complete program on real hardware
  • Locate and use the Arduino's built-in LED without any extra wiring
  • Change timing in a program and observe the effect on real hardware

1. Two Special Functions: setup() and loop()

Every Arduino program (called a "sketch") is built around two functions the board calls automatically — you never call them yourself:

FunctionRuns...Typical use
setup()Exactly once, when the board first powers on or resetspinMode() calls, Serial.begin(), one-time setup
loop()Repeatedly, forever, for as long as the board has powerEverything your program actually keeps doing
Connecting back to Lesson 1.4: loop() is, quite literally, an infinite loop — exactly the concept you learned in C++, just built directly into how the Arduino environment runs your code, rather than something you write yourself with while or for.

2. The Built-In LED

Every Arduino Uno has a small LED soldered directly onto the board itself, connected internally to a specific pin — almost always labelled "L" on the board and connected to digital pin 13. This means you can write and test your very first real program without wiring anything at all.

3. Step-by-Step: Blink

1Open a new sketch

In the Arduino IDE, start a new blank sketch (File > New).

2Write the code

void setup() {
    pinMode(13, OUTPUT);
}

void loop() {
    digitalWrite(13, HIGH);  // LED on
    delay(1000);             // wait 1 second
    digitalWrite(13, LOW);   // LED off
    delay(1000);             // wait 1 second
}

3Upload it

Click the Upload button (the right-pointing arrow) in the IDE. Watch the small status area at the bottom — it will show "Compiling," then "Uploading," then "Done uploading" if everything succeeds.

4Watch it run

The built-in LED (labelled "L") should now be blinking on and off, once per second, and will keep doing so indefinitely — even if you disconnect from your computer and power the board from a battery instead, since the program is now stored permanently on the board until you upload something else.

Troubleshooting

  • Upload fails with an error: double check the Board and Port are correctly selected under Tools, as covered in Lesson 3.1.
  • Code uploads but nothing blinks: confirm your specific board's built-in LED is genuinely on pin 13 — nearly all Uno-compatible boards are, but it's worth a quick check if using an unusual variant.
  • LED is on solidly, not blinking: check for a missing semicolon or misplaced bracket — reread your code carefully against the example above.

4. Why This Program Matters

This tiny program already demonstrates the complete pattern you'll use for the rest of the course: setup() configures a pin once, and loop() repeatedly acts on it. Every future lesson — controlling an external LED, reading a sensor, driving a motor — follows exactly this same shape, just with different pins and logic inside loop().

Try it yourself:
  1. Change both delay(1000) values to delay(200) and re-upload — confirm the blink speed changes.
  2. Make the LED blink with an uneven rhythm — on for 1 second, off for only 200 milliseconds.
  3. Add a Serial.println() inside loop() that prints "LED on" and "LED off" at the matching moments, and watch it in the Serial Monitor alongside the physical blinking.
  4. Challenge: using a for loop from Lesson 1.4, make the LED blink rapidly 5 times in a row, then pause for 2 seconds, then repeat.
