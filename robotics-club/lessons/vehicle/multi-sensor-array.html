Building a Multi-Sensor Array

Section focus: Robotic Vehicle — Line Sensor Subsystem — Lesson 4.1.2  |  Duration: ~50 minutes

Builds on: 3.13 Infrared Transmitters and Receivers (the sensor circuit), 1.5 Arrays, and 1.4 Loops. This lesson combines all three rather than re-explaining any of them.

Learning Objectives

By the end of this session, you will be able to:

  • Wire several IR reflectance sensors to separate analog pins
  • Store all their pin numbers and readings in arrays
  • Read every sensor in a single loop, rather than repeating code per sensor
  • Print all sensor readings at once for inspection

1. Choosing How Many Sensors, and the Spacing

Three sensors is a reasonable minimum for genuine steering decisions (left, centre, right); five gives finer detail for the proportional steering in Lesson 4.3.3. Space them evenly in a row, mounted facing down, with spacing narrow enough that the outer sensors sit just beyond the tape's width when centred — the exact spacing depends on your chassis and tape width, and is worth testing physically before committing to a permanent mount.

Figure 1: Five sensors in a row — S3 centred on the tape means "on course."

2. Wiring Multiple Sensors

Each sensor is wired exactly as in Lesson 3.13 — its own IR LED with a series resistor, its own phototransistor voltage divider — but each sensor's output goes to a different analog pin:

SensorAnalog Pin
S1 (far left)A0
S2A1
S3 (centre)A2
S4A3
S5 (far right)A4

All sensors share the same 5V and GND connections — only the signal output of each needs its own dedicated pin.

3. Reading All Sensors With an Array and a Loop

Rather than writing five nearly-identical analogRead() lines, store the pin numbers in an array and loop through them — exactly the pattern from Lesson 1.5:

const int sensorPins[5] = {A0, A1, A2, A3, A4};
int sensorReadings[5];

void setup() {
    Serial.begin(9600);
}

void loop() {
    for (int i = 0; i < 5; i++) {
        sensorReadings[i] = analogRead(sensorPins[i]);
    }

    for (int i = 0; i < 5; i++) {
        Serial.print(sensorReadings[i]);
        Serial.print("\t");  // tab-separated, easier to read in columns
    }
    Serial.println();

    delay(100);
}

Notice this is only a few lines longer than reading a single sensor — that's the entire benefit of arrays and loops from Section 1, now paying off directly.

Why const int sensorPins[5] instead of five separate variables? Beyond just saving typing, it means the loop's logic (read every sensor, print every sensor) is written once and automatically applies correctly no matter how many sensors are in the array — change the array to 3 or 7 sensors, and only the array declaration needs to change, not the loop itself.

4. Testing the Full Array

Upload the code above and open the Serial Monitor. Slowly slide the sensor array across a strip of tape by hand, and watch all five columns of numbers at once — you should see the values dip (or spike, depending on your wiring direction) one at a time as the tape passes under each sensor in turn.

Try it yourself:
  1. Build and wire at least 3 sensors (5 if your kit and chassis allow it) and confirm all read independently in the Serial Monitor.
  2. Slide the array over the tape by hand and confirm each sensor's reading changes as it passes over the dark line.
  3. Add a sixth column to your printout showing which sensor currently has the lowest (or highest, depending on wiring) reading — hint: this needs a variable tracking the "best so far" as you loop, similar to the "find the largest value" exercise from Lesson 1.5.
  4. Challenge: modify the array size constant to be stored in one place (e.g. const int NUM_SENSORS = 5;) and use it everywhere a "5" currently appears, so the whole program can be resized by changing one line.
