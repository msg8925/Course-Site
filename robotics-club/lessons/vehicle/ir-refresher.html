IR Reflectance Sensing Refresher

Section focus: Robotic Vehicle — Line Sensor Subsystem — Lesson 4.1.1  |  Duration: ~20 minutes

Prerequisite: this lesson assumes you've completed 3.13 Infrared Transmitters and Receivers. It won't re-explain how the IR emitter/receiver pair or voltage divider works — only what changes when moving from a single test sensor to a vehicle subsystem.

Learning Objectives

By the end of this session, you will be able to:

  • Recall the single-sensor circuit and code from Lesson 3.13
  • Identify what needs to change to use this sensor as part of a vehicle, not a standalone test
  • Explain why one sensor alone isn't enough to follow a line

1. What You Already Know

From Lesson 3.13, you should already be able to:

  • Wire an IR emitter LED and a phototransistor/photodiode receiver as a voltage divider
  • Read the receiver's output with analogRead()
  • Distinguish light and dark surfaces by comparing the reading to a threshold value

Everything electrically stays exactly the same in the vehicle build. What changes is scale and purpose: instead of one sensor tested by hand over different surfaces, you'll mount several sensors in a row, facing down, permanently positioned to straddle the tape line.

2. Why One Sensor Isn't Enough

A single downward-facing sensor can only tell you "light" or "dark" at one specific point. Imagine a vehicle with just one central sensor: as long as it's positioned exactly over a light surface, you know the tape isn't directly underneath it — but you have no idea whether the tape has drifted to the left or to the right. Steering correctly requires knowing which direction to correct toward, and that requires comparing readings from more than one position at once.

Looking ahead: Lesson 4.1.2 covers wiring and reading multiple sensors side by side, using exactly the array and loop techniques from Lessons 1.4 and 1.5 — reading five sensors will look like a small, natural extension of the single-sensor code you already have, not a rewrite.
Try it yourself:
  1. Without looking back at Lesson 3.13, try to redraw the IR sensor's voltage-divider circuit from memory, then check it against the original.
  2. Without looking back, try to rewrite the basic analogRead() and threshold-comparison code from memory.
  3. Sketch (on paper) what you think a 3-sensor arrangement might look like mounted on the front of a small vehicle, straddling a line of tape.
