Two-Motor Differential Drive with the L298N

Section focus: Robotic Vehicle — Drive & Motor Subsystem — Lesson 4.2.1  |  Duration: ~50 minutes

Builds on: 3.11 Driving a DC Motor with an Arduino (L298N). This lesson assumes you can already wire and control one motor through an L298N — here, you'll do exactly the same thing twice, using the driver's second channel.

Learning Objectives

By the end of this session, you will be able to:

  • Wire two motors to a single L298N's two independent channels
  • Control each motor's direction and speed independently
  • Explain what "differential drive" means and how it produces steering
  • Make the vehicle move straight, turn on the spot, and pivot around one wheel

1. What "Differential Drive" Means

Rather than a separate steering mechanism (like a front wheel that turns), this vehicle steers purely by running its two wheels at different speeds — exactly like a wheelchair or a tank. Both wheels forward at equal speed drives straight; slowing or reversing one wheel relative to the other curves or spins the vehicle. Every steering behaviour you'll ever need from this vehicle comes from varying these two motors relative to each other.

2. The L298N's Second Channel

You may not have noticed in Lesson 3.11, but the L298N module has two complete sets of control pins — one for each of its two channels. You were only using one:

4. The Code: Controlling Both Motors

const int leftIN1 = 8, leftIN2 = 9, leftENA = 10;
const int rightIN3 = 11, rightIN4 = 12, rightENB = 13;

void setup() {
    pinMode(leftIN1, OUTPUT);
    pinMode(leftIN2, OUTPUT);
    pinMode(leftENA, OUTPUT);
    pinMode(rightIN3, OUTPUT);
    pinMode(rightIN4, OUTPUT);
    pinMode(rightENB, OUTPUT);
}

void loop() {
    // Both motors forward at full speed
    digitalWrite(leftIN1, HIGH);
    digitalWrite(leftIN2, LOW);
    analogWrite(leftENA, 255);

    digitalWrite(rightIN3, HIGH);
    digitalWrite(rightIN4, LOW);
    analogWrite(rightENB, 255);
}

With the vehicle raised off the ground (wheels not touching anything), upload this and confirm both wheels spin forward together.

Troubleshooting

  • One motor spins backward relative to the other when both should match: this is very common due to how the motors are physically mounted (mirror images of each other) — simply swap that motor's two OUT wires rather than changing your code's logic.
  • Motors run at different speeds despite identical code: small manufacturing differences between motors are normal — Lesson 4.2.2's movement functions are a good place to add a small speed-correction offset if needed.
  • Nothing moves at all: check the external battery pack is switched on, exactly as in Lesson 3.11.
Try it yourself:
  1. With the vehicle raised off the ground, confirm both wheels spin forward together.
  2. Test each behaviour in the table above and confirm the vehicle does what you expect once placed on the ground.
  3. If one motor spins faster than the other at the same PWM value, find a speed adjustment (e.g. 255 vs 240) that makes them visually match.
  4. Challenge: write code that gradually ramps both motors from 0 to full speed over 2 seconds, rather than jumping straight to full speed.
