E1. State two reasons why algorithms are often written in pseudocode rather than in a programming language.[2]
Show mark scheme

One mark per point, maximum 2:

  • It is not tied to a particular programming language, so any programmer can understand it / convert it into their own language.
  • It lets the programmer focus on the logic of the algorithm without worrying about exact syntax.
  • It is easier to read and understand than program code, including for non-programmers.
  • It is quick to write, so an algorithm can be planned before coding.
E2. Rewrite this code so that it follows the Cambridge pseudocode conventions and uses a meaningful identifier.[4]
pseudocode
declare x : INTEGER
x = 5
x = x + 1   # add one to the counter
output x
Show mark scheme
model answer
DECLARE Counter : INTEGER
Counter ← 5
Counter ← Counter + 1   // add one to the counter
OUTPUT Counter

One mark each:

  • Keywords DECLARE and OUTPUT in upper case.
  • ← used for both assignments.
  • Comment starts with //.
  • Meaningful identifier (e.g. Counter) used consistently on every line.
E3. Study this program.[3]
pseudocode
DECLARE Width : INTEGER
DECLARE Height : INTEGER
DECLARE Area : INTEGER
Width ← 6
Height ← 4
Area ← Width * Height
Width ← 10
OUTPUT Area

(a) State the value that is output. [1]
(b) A student expected the output to be 40. Explain why the program does not output 40. [2]

Show mark scheme
  • (a) 24
  • (b) Area is calculated and stored when line 6 runs, using the value of Width at that moment (6)… [1]
  • …changing Width afterwards does not recalculate Area, because the calculation is not run again / assignment stores a value, not a formula. [1]
