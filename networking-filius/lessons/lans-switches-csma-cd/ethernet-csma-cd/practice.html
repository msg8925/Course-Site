2. Why do fewer collisions happen on a modern switched network than on an old shared-cable network?

Reveal model answer
A switch gives each device its own dedicated link rather than making every device share one physical cable, so far fewer devices are competing for the same medium at once.

C

The sequence

6. Put these CSMA/CD stages in the correct order (1 = first):

  • :: Collision detected between two devices
  • :: Device listens to the cable (carrier sense)
  • :: Both devices wait a random backoff time
  • :: Cable is free, so the device sends

7. Why does the backoff time need to be random rather than a fixed length?

Reveal model answer
If every device waited the same fixed time, they would all retry at exactly the same moment and collide again — a random wait spreads out the retries so they're less likely to clash a second time.

E

Exam-style question

10. Explain why CSMA/CD is necessary on a shared-medium network, and describe what happens when two devices transmit at the same time.

Reveal model answer
Because multiple devices share the same physical cable, there needs to be a rule for taking turns to avoid constant data corruption. CSMA/CD requires a device to listen before sending (carrier sense); if two devices sense the cable is free and send at the same time, their signals overlap and both devices detect this collision. Both then stop transmitting and wait a random backoff period before retrying, reducing the chance of an immediate second collision.

11. A network technician says: "Since we upgraded from a shared hub to a switch, collisions have almost disappeared." Explain why this is true.

Reveal model answer
A hub forwards every signal to every connected device over a shared medium, so devices are still competing for the same cable and collisions remain likely. A switch instead gives each device its own dedicated connection and forwards frames only to the intended destination port, so far fewer devices are ever contending for the same link at once.
