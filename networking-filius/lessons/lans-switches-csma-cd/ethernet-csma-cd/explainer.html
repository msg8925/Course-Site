01

What is Ethernet?

Ethernet is the dominant LAN standard. It defines how devices frame and address data for transmission — and, critically, how devices sharing one physical cable take turns without constantly talking over each other.

Why this mattersModern switched networks (like the one you built in Session 3) have far fewer collisions than the old shared-cable networks Ethernet was originally designed for — but the underlying rules are still worth understanding.
02

CSMA/CD, stage by stage

CSMA/CD stands for Carrier Sense Multiple Access with Collision Detection. It's the set of rules that let multiple devices share one cable.

1 · CARRIER SENSE

Listen to the cable before sending anything.

2 · MULTIPLE ACCESS

Many devices share the same cable — nobody owns it.

3 · COLLISION DETECTION

Two devices sent at once — both detect the clash.

4 · RANDOM BACKOFF

Both wait a random short time, then try again.

04

The role-play

  1. 5–6 students represent devices on a shared "cable" (a length of string or a marked line on the floor).
  2. Each holds a card with a message to "send"; check whether anyone else is already sending before you do.
  3. A simultaneous send is a collision — both students stop, roll a die, wait that many seconds, then retry.
  4. Repeat with more "devices" and watch collisions become more frequent.
