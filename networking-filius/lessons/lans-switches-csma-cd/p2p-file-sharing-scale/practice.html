Discovery and resilience

3. What can still be a challenge in a P2P network, even though there's no single point of failure for a file?

Reveal model answer
Discovery — finding out which node(s) currently hold a copy of the file you want.

4. Only ONE laptop has ever held a particular file, and no one else has downloaded it yet. If that laptop goes offline, what happens to the file?

It automatically copies to another laptop It becomes unreachable Nothing changes

5. Explain why P2P redundancy depends on a file having actually "spread" to multiple nodes.

Reveal model answer
If only one node has ever held the file, there is no backup copy elsewhere — the resilience of P2P only comes from multiple nodes actually holding copies, which only happens once other nodes have downloaded it.
C

P2P vs client-server

6. In a client-server setup, what happens if the server goes offline?

Nobody can access anything Clients automatically become servers Nothing changes

7. Give one advantage of P2P file sharing over a single central server.

Reveal model answer
No single point of failure for the file itself — the network doesn't depend on one central machine staying online.

8. Give one disadvantage of P2P file sharing compared with a single central server.

Reveal model answer
Harder to control or guarantee availability — a file's availability depends on which nodes happen to be online and whether they've downloaded a copy, rather than one reliably maintained server.

E

Exam-style question

11. A small business is deciding between a P2P file-sharing setup and a single central file server for sharing documents between 5 employees' laptops. Discuss one advantage and one disadvantage of each approach, and recommend which is more appropriate.

Reveal model answer
P2P advantage: no single point of failure — if one laptop is offline, files that have spread to other laptops remain accessible. P2P disadvantage: harder to guarantee a file is available, and no central point for backups or access control. Client-server advantage: centralised control, easier backups, and predictable access. Client-server disadvantage: if the server goes down, nobody can access any files. For a small business needing reliable access and control over shared documents, a central file server is likely more appropriate, provided it is properly backed up — the P2P model's resilience matters more at a larger scale where any single machine failing is a smaller proportion of the whole network.
