PART A

Build the network

Build a 3-laptop network connected via a switch. Configure the file-sharing service on the nodes, then share a file from one laptop and download it from another.

PART B

Watch the traffic

Slow the simulation speed and observe the request/transfer traffic on the switch. Describe what you see happening.
PART C

Add a third laptop

Add a third laptop to the network mid-transfer. If the laptop holding the original file went offline, could the third laptop still get the file? Explain your reasoning.
PART D

Compare to a single point of failure

What would happen if this were a client-server setup instead, and the single server went offline? How is this different from the P2P case above?
PART E

Independent task: advantages and disadvantages

List two advantages and two disadvantages of P2P file sharing compared with a single central file server.
