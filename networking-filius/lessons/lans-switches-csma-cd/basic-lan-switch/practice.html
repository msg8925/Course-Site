6. Explain one difference between a switch's MAC address table and a PC's ARP table.

Reveal model answer
The switch's table maps MAC addresses to physical ports so it knows where to forward frames; a PC's ARP table maps IP addresses to MAC addresses so the PC knows who to address data to.

ARP at scale

7. Four PCs share a switch. Only PC1 has ever pinged PC2. What is in PC3's ARP table?

8. Why doesn't adding more PCs to a switch automatically fill in everyone's ARP tables?

Reveal model answer
An ARP entry is only created when a device actually needs to resolve another device's MAC address — being connected to the same switch doesn't trigger that on its own.

Exam-style question

12. A technician claims that connecting four PCs to the same switch means every PC "automatically knows" every other PC's MAC address. Explain why this claim is incorrect, and describe what would actually need to happen for two specific PCs' ARP tables to gain entries for each other.

Reveal model answer
Being connected to the same switch only provides the physical path for data to travel — it doesn't automatically populate ARP tables. Each PC's ARP table only gains an entry for another device once it actually needs to communicate with it, triggering an ARP request and reply between those two specific devices. For two PCs to learn each other's MAC addresses, one would need to send data (e.g. a ping) to the other, prompting the ARP resolution process.
