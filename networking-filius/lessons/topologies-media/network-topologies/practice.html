Star

3. In a star topology, what does every device connect directly to?

4. What is the single point of failure in a star topology?

Any one PC The central switch The cable between two PCs

5. If one PC's cable to the switch fails in a star network, what happens to the rest of the network?

Reveal model answer
Nothing — every other PC still has its own separate link to the switch, so only the one PC with the broken cable loses connectivity.
C

Bus

6. In a bus topology, what do all devices connect to?

A central switch One shared cable Every other device individually

7. What is fitted at each end of an older coaxial bus cable, and why?

Reveal model answer
A terminator, which absorbs the signal at the end of the cable and stops it reflecting back down the wire and causing interference.

8. Why does a single cable break affect a whole bus segment, unlike a star?

Reveal model answer
Every device shares the same physical cable rather than having its own separate link, so a break anywhere along that shared cable can stop signals reaching devices on the other side of the break.
D

Mesh

9. What is the key difference between a full mesh and a partial mesh?

Reveal model answer
In a full mesh, every device has a direct link to every other device. In a partial mesh, devices only connect directly to some of the others, not all.

10. Why is mesh generally the most fault-tolerant topology?

It uses the least cable There are usually multiple routes between any two devices It only needs one central device

11. Why can't Filius easily build a full mesh of more than 3–4 PCs?

Reveal model answer
Filius limits how many network connections a single node can have, and a full mesh needs every device to connect directly to every other device — so the number of connections per device grows quickly as more devices are added.
E

Exam-style

12. A small data centre wants the highest possible resilience between its core routers and is prepared to pay for extra cabling. Which topology should it choose, and why?

Reveal model answer
Mesh (full or partial) — because it provides multiple routes between devices, so a single failed link is unlikely to disconnect any device, which is worth the extra cabling cost for critical infrastructure.
