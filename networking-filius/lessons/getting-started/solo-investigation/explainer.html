01

What is an IP address?

An IP address is a numerical label assigned to a device on a network. It does two jobs: it identifies the device, and it gives other devices somewhere to send data back to.

Real-world analogyAn IP address works like a postal address — it doesn't describe who you are, only where to find you on the network right now.

IPv4 addresses (the kind you'll see today) are written as four numbers separated by dots — e.g. 192.168.1.14 — each number between 0 and 255.

02

The Network Interface Card (NIC)

The NIC is the piece of hardware — built into your laptop or added as a separate card — that actually connects a device to a network. Every NIC has a unique physical (MAC) address burned in at manufacture, which is different from the IP address it's assigned.

04

ping and ARP

ping sends a small test message to another device and waits for a reply — a quick way to check whether two devices can reach each other.

CMD
C:\> ping 192.168.1.22

Reply from 192.168.1.22: bytes=32 time<1ms TTL=128
Reply from 192.168.1.22: bytes=32 time<1ms TTL=128

Before your device can send that ping, it needs to know the destination's MAC address — that's what ARP (Address Resolution Protocol) resolves. Run arp -a before and after a ping and you'll see a new entry appear.

Watch for thisAn empty ARP table doesn't mean nothing is connected — it means your device simply hasn't needed to talk to that device yet.

06

Practical lab steps

  1. Run ipconfig on your own machine — note the IPv4 address, subnet mask, default gateway, and physical (MAC) address.
  2. Run ipconfig /all for full adapter detail.
  3. Pair up, exchange IP addresses, and ping your partner's machine.
  4. Run arp -a before and after the ping — what changed?
  5. Find the same settings via Windows Settings > Network & Internet.
  6. Watch the demo: configuring a static IP address via the GUI.
