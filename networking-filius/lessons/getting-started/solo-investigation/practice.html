Exam-style question

12. A student says: "My laptop's IP address never changes, so it must be static." Explain why this reasoning could be wrong, and describe one way to check.

Reveal model answer
A dynamic (DHCP-assigned) address can stay the same for a long time if the lease keeps renewing to the same address, so an address not changing doesn't prove it's static. To check, look at whether "DHCP Enabled" is shown as Yes or No in ipconfig /all — if DHCP is enabled, the address is dynamic even if it hasn't changed recently.
